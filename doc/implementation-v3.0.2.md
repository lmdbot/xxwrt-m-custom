## 未声称完成/限制

- 真机 QWRT/OpenWrt 不同插件、ACL 和设备场景尚未由本次工作逐项测试。
- 设计原型展示的示例速度、路由器名称、在线数量不是 APP 的默认数据；正式界面无虚构数据。
- 未引入新的后台长期采样能力、OpenClash 未授权 Controller API 或新的危险操作权限。
- 完整按页像素级一致需要多机型截图回归；本次采用设计语义和真实业务组件，非把 SVG 贴到屏幕上。

## 补充实施：统一交互、跨来源终端、设计 Token（2026-11-17）

- 终端页将 DHCPv4、DHCPv6、Wi-Fi 与 OpenAppFilter 的实际可读记录按 MAC 归一合并；搜索和在线状态筛选对全部来源一致生效，避免同一 MAC 重复展示。OpenAppFilter 出现不代表在线，仍以无线关联/邻居证据为准。
- 各来源共用 `TerminalDeviceCard`，补齐“应用用户”来源标签；不可读时区分无无线射频/权限不足/插件不可读，不宣称已安装或在线。
- 首屏健康卡允许点击/键盘进入系统硬件展开状态；实时流量卡允许直接进入详细监控，复用现有真实采样，绝不写入演示曲线。
- 顶部路由器选择控件覆盖工作区全部主页面及“我的/设置”；调优窄屏触控尺寸，避免顶栏重复显示设备名。
- 在 `src/style-v3.css` 定义浅/深语义 Token，`src/main.js` 主题补齐次色、警告色及深色文本；Android 状态栏主题与 `doc/04-design-system.md` 背景对齐，360–430dp 概览 KPI 切换为 2×2、23px 数字，符合规范的 22–28sp。
- Playwright 断言随设计变动调整：关于版本从 `package.json` 获取；展开硬件后验证刷新保持；DHCPv4 测试显式筛选；增加全来源去重、OpenAppFilter 搜索等回归。

### 仍需验收

- 这些修改已提交到 PR 开发分支，合入 `main` 前必须以该分支最新提交的完整 CI 成功结果为准；历史版本构建成功不能代替新提交的验证。
- `doc/visuals/*.svg` 与 `prototype.html` 是交互说明/参考效果，不是逐页面真机像素差异的自动验收结果。插件详情、路由器不同 ACL、Android 多密度/字体放大/深浅色及不同固件仍须截图对照和真实 QWRT/OpenWrt 联调。
- 新增行为仅影响界面和真实读取数据整合，未改动网络、防火墙、UCI、恢复、重启等服务端写入参数与安全回滚机制。

## 手工验证建议

1. 360/393/430dp 下五栏完整可点，顶部当前路由器可切换且显示省略号。
2. 概览首屏健康/四 KPI/流量/快捷，详情折叠；网络接口快捷返回概览。
3. 设备页全部来源不重计同 MAC 终端，支持在线/离线/未知；DHCP 租约不误判在线。
4. 网络页接口/物理/无线从 hub 直达，不重复分类；配置回滚无法通过 Back 绕过。
5. 工具 28 功能入口完整，插件缺失与 ACL 不足有明确提示；恢复出厂仍有强确认。
6. 我的三组内容和简体/繁体/英文切换正常；浅/深主题、系统字体放大可读。
