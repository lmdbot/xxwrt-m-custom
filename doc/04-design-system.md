# 04 · Material 3 + 轻玻璃设计系统

> 设计 Token 是**目标规范**，不是宣称所有现有组件已使用这些值。组件应优先利用 Vuetify 3 主题系统和现有 `style-v3.css`，新增样式用语义变量，不散落十六进制颜色。

## 1. 视觉目标

基调为专业的网络运维控制台：白/浅蓝背景、克制的湖蓝点缀、清晰的信息分组、明确的连接状态。轻玻璃只用于顶部 App Bar、底部导航与少量无数据的装饰背景。**图表、告警、表单、地址、密钥、规则表**必须使用实色面板以保证阅读性。

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--ui-primary` | `#2477EE` | `#83B6FF` | 主操作、选中 |
| `--ui-secondary` | `#23A2CF` | `#4ACBE2` | 速度/网络次轴 |
| `--ui-teal` | `#168E8B` | `#62CEC0` | 辅助强调 |
| `--ui-bg` | `#F3F7FD` | `#0F1727` | 背景 |
| `--ui-surface` | `#FFFFFF` | `#182437` | 主内容卡 |
| `--ui-surface-2` | `#EAF1FC` | `#23324A` | 次级背景 |
| `--ui-text` | `#12233F` | `#F2F7FF` | 主文本 |
| `--ui-muted` | `#63758E` | `#A9B7CC` | 辅助文本 |
| `--ui-border` | `#DCE6F4` | `#34445C` | 分割线 |
| `--ui-success` | `#14AA65` | `#56D59B` | 已验证的正常 |
| `--ui-warning` | `#D9981F` | `#F4BE65` | 警告/待确认 |
| `--ui-error` | `#DC505B` | `#FF8790` | 失败/危险 |
| `--ui-unknown` | `#8797A9` | `#98A7BB` | 未知/无证据 |

连接状态的文案必须参与传达，**不得只有颜色**。联网正常与“RPC 可访问但未认证”不可使用同一个绿色标记。

## 2. 字号层级

| 层级 | 大小/行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 页面大标题 | 22 / 28sp | 700 | 概览/工具根 |
| 页面标题 | 20 / 26sp | 700 | 二级标题 |
| 组标题 | 16 / 23sp | 700 | 网络服务、系统维护 |
| 卡片标题 | 15 / 22sp | 650 | 功能名/设备名 |
| 正文 | 14 / 21sp | 400–500 | 数据与描述 |
| 辅助 | 12 / 18sp | 400–500 | IP、型号、来源 |
| 标签 | 11 / 16sp | 650 | 状态 Chip |
| KPI 大数字 | 22–28 / 30sp | 700 | CPU、速率 |

默认使用 `Roboto` + Android 系统中文字体回退，禁止把远端字体作为必需依赖。需适配系统字体放大 1.3×，重要数据与按钮不截断。

## 3. 栅格 / 间距 / 圆角

- 最窄基准 360dp，侧边距 16dp；393dp 可使用 18dp。内容区最大宽度 760dp，平板可切分双栏。
- 4dp 基础网格；卡片间距 12dp、组间距 20dp；卡内间距 12–16dp；操作表单段间距 16–24dp。
- 大卡片圆角 20dp；普通卡片 16dp；控制项 12dp；状态 Chip 999dp；独立玻璃底栏 20–24dp。
- 底栏高度 68dp + `safe-area-inset-bottom`；顶部 App Bar 56–64dp + 状态栏安全区。
- 点击/滑动目标最小 48×48dp，紧凑图标按钮允许可见尺寸更小但点击热区不变。
- 纵向列表信息密度 64–76dp/行；可展开内容不能默认全部展开。

## 4. 组件清单

| 组件 | 原则 | 约束 |
| --- | --- | --- |
| `RouterSelector` | 统一设备头像/名称、连接状态、下拉选择 | 切换前处理未保存编辑 |
| `HealthHero` | 一条状态摘要 + 设备型号/运行时长 | 状态未确认不能显示绿色 |
| `MetricTile` | 数值 + 单位 + 来源/范围（可选） | 缺失用“—”，不填 0 |
| `MiniTrafficChart` | 两条折线、RX/TX 实值 | 至少两个有效采样再绘图 |
| `FeatureRow` | 图标、标题、可选摘要、状态、箭头 | 未安装/权限不足要明确原因 |
| `ClientCard` | 设备类别/名称、IP/MAC、在线证据 | 租约≠在线 |
| `ToolCategory` | 组标题+项数+折叠 | 默认打开最常用组，其余可折叠 |
| `StatusChip` | 正常/异常/未知/不可读等 | 图标+文字，深浅主题一致 |
| `EditSheet` | 标题、影响说明、表单、底部保存 | 键盘显示时可滚动 |
| `SafeConfirm` | 操作目标、影响、回退窗口、按钮 | 危险按钮不放首要位置 |
| `InlineFeedback` | 页面内结果 + 必要 Snackbar | 需可复制诊断信息 |
| `EmptyState` | 状态原因、行动按钮、支持链接 | 不得使用虚拟统计填空 |

## 5. 玻璃与层级

`backdrop-filter: blur(12–16px)` 仅用于 Top Bar/Bottom Bar；不支持的 Android WebView 回退为不透明面板。玻璃面 opacity ≥0.88，标题/主要图标要满足文字对比度；数字区固定纯色 Surface，避免速度曲线与背景叠层。阴影低对比，层级优先靠间距而非投影。

## 6. 图标映射

一级：概览 `mdi-view-dashboard-outline`、设备 `mdi-devices`、网络 `mdi-lan`、工具 `mdi-apps`、我的 `mdi-account-circle-outline`；保留 Material Design Icons，统一线性风格与 20–24dp 主规格。状态类（成功/错误/警告）不使用与操作类重复的颜色语义。

## 7. 响应式/无障碍

- 360dp：五个底栏均可显示完整中文两字标签；不会出现横向溢出；快捷操作 4 列、KPI 2×2。
- 393–430dp：KPI 可按 2×2 或 4×1，优先确保数字不截断。
- ≥600dp：最大宽 760dp，网络设置/系统工具可双栏；不新建桌面侧栏以免与五底栏理念冲突。
- 颜色对比（主要文字至少 4.5:1）、明确焦点态、语义 aria-label、动态区域 `aria-live`、减少动效偏好。
- 深色主题不是简单反相：图表独立线条、网格与状态色重新调亮，阴影变弱、描边变强。
