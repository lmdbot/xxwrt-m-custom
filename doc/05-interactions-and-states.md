# 05 · 交互模型、异常状态与安全守则

## 1. 路由器连接和能力状态

状态类型独立维护，不用一个 `online` 覆盖全部语义。

| 状态 | 用户看见 | 可执行 |
| --- | --- | --- |
| 尚未添加路由器 | 欢迎页：添加路由器、连接说明 | 仅添加、我的/设置 |
| 已保存/检测中 | 地址 + “正在检测” | 编辑、手动重试 |
| 可达但未登录 | “可以连接，尚未认证” | 登录；敏感数据不可见 |
| 已连接 | 最近刷新时间 + 已读数据 | 按权限展示功能 |
| 不可达 | “路由器暂时无法访问” + 原因 | 重试/切换/编辑 |
| 无 RPC 权限 | “无法读取此能力” + 排查 | 禁用需要权限的写入 |
| 未安装插件 | “未检测到插件”仅在能明确判定时显示 | 安装指引而非假开关 |
| 能力未知 | “无法确认” | 重试/查看检查方法 |
| 数据过期 | “上次更新于 …” | 保留旧值但标记过期 |

切换路由器必须清空上一台设备的敏感实时值，尤其 WAN IP、终端名称、规则和缓存会话；失败时不能回退展示上一台路由器的图表。

## 2. 查询、刷新与错误处理

- 无数据与 0 分别表示；采集/授权错误显示“—”并给出可理解的原因。
- 页面级刷新保留用户筛选与滚动位置；搜索采用 150–250ms 去抖，搜索后结果数与清除按钮可见。
- 图表：`network.device.status` 计数器需两次有效采样；计数器回绕、接口切换、失败时断线而非拼接假数据。
- 核心页面只展示小摘要，点卡片进入详情；超过两层时使用面包屑式二级标题或明确的顶栏返回。
- 操作执行后先显示“已提交”，收到成功响应且重新读取后才显示“已生效”；失联为“结果未知，请核实”，不是一概成功或失败。
- `Snackbar` 只用于轻量提示；不可撤销操作的失败、修改差异和重试链接采用页内常驻反馈，不能 5 秒消失。

## 3. 危险操作分级

| 风险 | 示例 | UI 机制 |
| --- | --- | --- |
| R0 只读 | 监控、查看终端、路由状态 | 直接查看 |
| R1 可逆小改动 | 修改收藏、隐藏 IP、APP 主题 | 即时保存/可撤回 |
| R2 业务可感知 | DDNS、服务重启、Cron、静态租约、插件启停 | 操作目标+影响提示+结果复核 |
| R3 可能断连 | WAN、IPv6、防火墙区域/转发、配置恢复 | 差异预览+显式确认+回滚倒计时+重新验证 |
| R4 不可逆/大影响 | 恢复出厂、重启主路由、危险软件包操作 | 强确认/输入关键词/默认取消/阻止误触 |

R3 维护现有 UCI 保护机制与确认时间窗口；不更改实际回滚时间。配置恢复已经使用 90 秒倒计时，其余网络/防火墙以相关服务的现有实现参数为准。对于 APP 切后台、杀进程、通信失败也要保留“待确认/未知”口径。

## 4. 关键用户路径验收

### 4.1 首次使用
打开 APP → 路由器管理空态 → 添加路由器（URL、用户名、密码、HTTPS 风险提示）→ 检测与登录 → 概览。无会话时设备/网络/工具应显示有意设计的禁用态/连接引导，不启动模拟数据。

### 4.2 故障排查
概览 WAN 异常 → 网络接口 → WAN 详情 → 原始状态/网关/DNS → 工具·网络诊断；返回按来源恢复“网络接口详情”，不是跳到工具首页。

### 4.3 终端管控
设备筛选 → 搜索 MAC → 终端详情 → 查看来源证据 → 按权限进入静态 IP/限速 → 验证 → 返回列表同一筛选。仅 DHCP 租约不能直接推出在线。

### 4.4 插件运维
工具 → 插件中心 → SSR/OpenClash/Lucky → 服务状态 → 配置变更 → 验证/日志 → 返回插件列表。插件不可读时展示权限/能力诊断，不能显示“0 个插件”。

### 4.5 配置恢复
工具 → 维护与备份 → 选择 UCI JSON 快照 → 校验文件/预览 diff → 输入“恢复配置” → 应用中 → 限时确认保留/回滚 → 重新读取结果 → 审计记录。未完成不可静默退出。

### 4.6 切换路由器
任意根页 → 顶部选择器 → 路由器列表 → 登录/复用有效会话 → 概览；涉及未保存编辑、UCI 回滚进行中时阻止或先明确中止。收藏与终端缓存必须按路由器隔离。

## 5. 表单规范

- 显示单位和地址示例：IPv4/IPv6、CIDR、MAC、端口、Cron 表达式，需有就地校验。
- 仅在 API 支持时显示可写；未知能力时显示带说明的禁用项，不用“保存成功”模拟。
- 固定底部操作区包含「取消」与「保存/应用」，为高风险写入增加影响说明及差异查看。
- 不自动重试可能重复执行的写入操作；提供“查询当前结果”优先于再次提交。
- 口令、Token、密码不要落在本地操作日志或截图示意、GitHub 文档示例里。

## 6. 遥测和隐私

流量图真实 RX/TX，明确速率单位 Mbps/MB/s；网络状态“未连接/无法确认/可达/已登录”各有标识。Android Credential 必须继续安全存储；HTTP 访问仅提示可信 LAN/VPN 条件并允许用户理解风险；保留显示名称/IP 单独遮挡与本地持久化。30 天趋势仅在 APP 有效采样，不能宣称全时后台监控。

## 7. 与现有实现相容

无需一次性重写整个 `App.vue`。优先抽出纯导航状态 `routeStack`，复用已有 `toolPanel`、`networkSection`、登录和采样服务。所有后续迁移需同时修改导航回归、组件 UI 回归和 RPC mock 测试。
