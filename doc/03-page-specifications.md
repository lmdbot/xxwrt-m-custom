# 03 · 页面级详细 UI/UX 规范

> 标准画板：393×852dp（辅测 360×800dp、430×932dp）；顶部区域含 Android 安全区，底部五栏与系统手势条不冲突。示例 IP、速率、设备名均为演示内容，不是实时连接数据。

## A. 五个一级页面

### A1. 概览（Overview）

**Top App Bar**：左侧「XX-WRT / 当前路由器」下拉；右侧刷新及通知（仅有真实通知来源时显示）；断线时突出重连。首屏顺序：① 连接健康横向英雄卡（状态/型号/运行时长；未确认不涂绿）② CPU/内存/存储/终端 2×2 或横排四指标 ③ 实时下行/上行简化 60–90 秒曲线（无样本显示采样中）④ 四快捷「接口/防火墙/DDNS/诊断」⑤ 折叠的硬件详情。滑动到页面底部出现跳转「详细监控」。

**交互**：点健康卡查看系统详情；点曲线跳详细监控；点快捷直达原功能详情，返回概览原位置。拉下刷新只刷新当前路由器，不重置滚动。点击“长趋势”再进入本地 30 天图页。指标顺序可未来扩展，不是本阶段必做。

**主要状态**：无路由器→引导添加；未登录→连接/凭据入口；无法读取→占位符和重试；真实采样不足→“等待第二次采样”；高负载→说明警告来源，不推定故障。

### A2. 设备（Devices = 终端）

页面标题使用「终端设备」，但底栏保持用户确认的「设备」。顶部**已确认在线/仅检测到/未知**分项统计（不把 DHCP 租约全部算在线）；首选筛选是「全部、在线、离线/未知」，第二行轻量来源 Chip「DHCPv4 / DHCPv6 / Wi-Fi / 应用用户」。统一搜索名称、IP、MAC；列表卡展示名称、IP、设备类型、来源、在线证据；右上更多隐藏 IP 与排序。底部“家长控制”“网络唤醒”常用入口，或作为顶部次级快捷卡（取决于 360dp 空间）。

**终端卡点击** → 终端详情；**长按/尾部菜单** → 可用操作菜单（静态租约/限速/WOL 等，按权限显示）；不在列表内直接放多个危险按钮。UI 允许状态为「在线/离线/待确认」，并在详情解释判断依据。

### A3. 网络（Network）

首屏 3 小型概要 KPI：WAN/ LAN/ IPv6（不要显示未经验证的 “IPv6 正常”）。列表按两组排列：
- 连接与接口：网络接口、物理设备、无线设备。
- 服务与策略：路由表、DNS / DHCP、防火墙、DDNS、ZeroTier。

每行前缀语义图标 + 标题 + 关键摘要 + 状态标签 + 尾部箭头。接口详情可见 WAN/LAN/WAN6/PPPoE、IPv4/IPv6/IPv6-PD、DNS/网关/MTU/接口运行时间；网络硬件及无线参数提供只读状态与明确说明。编辑网络的页面必须将“已保存/应用中/待确认回滚”固定在显眼位置。

### A4. 工具（Tools）

首页：搜索框（跨 28 个可用功能的标题/别名/分类）；**最多五个收藏快捷入口**（沿用按路由器保存的收藏）+ 编辑；四个可展开分类组「插件中心、系统管理、诊断与安全、维护与备份」。已安装/未安装/ACL 不足/检测中标记在插件行尾，不把“不可读”渲染成“未安装”。

建议第一屏露出收藏和至少一个完整分类区块。危险功能「重启」「恢复出厂」仅放在维护与备份末尾，恢复出厂加红色语义和额外阻隔。插件中心仅为**路由器插件管理入口集合**，不是应用商店；软件包使用现有 opkg 功能。

### A5. 我的（Me）

首屏应用名、图标、当前版本和简短连接摘要。三组纵向：① 路由器（管理设备/当前路由器/退出会话）② 应用设置（显示、隐私、刷新、语言、实验室；可首屏只展示常用、点击“全部”展开）③ 支持与更新（关于 XX-WRT、检查更新、反馈/许可证由关于页统一整理）。不要再放左侧全局抽屉；「关于/开发者」不与路由器设置互相混杂。

## B. 十一个重点二级页面

### B1. 详细监控（概览下钻）
顶部当前采样网口下拉（默认 WAN，如无则可用接口），实时 RX/TX 数字、实时折线、平均/峰值、CPU/内存/系统负载（1/5/15 分钟），末尾「长期趋势」入口。明确“只展示真实计数器”与“本地采样不等于后台全年监控”。每张图高度 170–220dp，可横向切换时间尺度但不能伪造历史。

### B2. 终端详情
固定上方「名称/设备类别/是否在线（带证据）」；地址信息组 IP4/IP6/MAC/主机名、来源与租约；连接信息组 AP/频段/信号（有据才展示）；操作区静态 IP、限速或 HQoS、网络唤醒、家长控制规则。编辑动作打开独立 Sheet；保存前校验 IP/MAC/配置权限，执行后重读。历史应用访问记录不可因示意图而宣称可用。

### B3. 网络接口
「WAN/LAN/WAN6/自定义」列表按状态展示协议、IP、速率/运行时间；详情可查看 IPv6 前缀、PD、DNS、网关、MTU、网卡。配置项按「基础/IPv4/IPv6/高级」分段。写入后需要确认保留或超时回滚；断连提示“结果未知”，而不是强制显示成功。

### B4. 防火墙
主状态卡含 firewall 服务状态与能力信息，下面 4 子栏/列表入口：区域策略、通信规则、端口转发、访问控制（仅现有 RPC 能力可达时提供）。策略列表必须可辨协议、源区域、目标区域、动作和启停；不支持的编辑不能以假输入框冒充功能。规则更改前差异对比，异常回退/重读。

### B5. DNS / DHCP
顶部「静态 DHCP / 本地域名」分段，输入合法性与重复冲突在表单即时反馈；动态 DHCP 租约信息不混入静态记录编辑；保存后提示 dnsmasq 重载是否已确认。支持 IPv4 与 IPv6 字段需依据路由器能力显示。

### B6. DDNS / ZeroTier
两者分别有独立详情页：DDNS 显示服务/域名/最近更新/日志、脚本型与 DDNS-Go 的不同可编辑范围；ZeroTier 显示服务、已加入网络、Network ID、分配地址、成员状态与授权提醒，区分“已加入”与“中心已授权”。

### B7. 插件中心与插件详情
分类列表列出 SSR Plus+、OpenClash、Lucky、微信推送、Vlmcsd、Internet Detector、Carbon；可用插件显示实时服务状态；不可读显示原因和诊断入口。进入详情后统一壳层：运行状态头卡 → 常用操作 → 配置分组 → 日志与高级；各插件的真实控件来自已有组件，不在无权限时放虚假的开关。

### B8. 服务与软件包
服务列表支持关键字、运行/自启状态、可控操作；危险关键服务禁用。软件包分「已安装/可安装/更新」前先确认索引可用；操作要显示具体进度和结果，不将 opkg 失败包装成功。需保留大小/版本/来源等能够读取的字段。

### B9. 日志/诊断/安全
网络诊断内置 Ping、Traceroute、DNS 查询分段；日志提供系统/内核/审计来源切换及搜索/复制；安全分析与能力识别基于现有记录呈现置信度和来源。无证据时不展示虚构攻击数、可疑 IP 评分或无来源风险排行。

### B10. 备份与恢复
顶部「配置备份」「恢复配置」「备份文件」三块。明确两种不同格式：**UCI JSON 快照**与**系统原生 tar.gz**；不可互换。当选择恢复时，先差异预览（变更数量/配置键）→ 输入确认文案 → 应用/90 秒倒计时 → 保留或回滚；关闭前提醒。文件可能含密码/密钥，显示隐私提示。

### B11. 我的 → 设置 / 关于
设置目录可直达显示（跟随系统/浅/深、底栏风格、列表密度）、隐私（隐藏路由器地址/名称）、刷新（频率/后台限制说明）、语言（简中/繁中/English）、实验室（能力说明与风险）。关于页沿用现有独立 `AboutPage.vue` 的应用信息、开发者项目、当前版本/构建、正式版更新、日志、仓库/反馈/开源许可与隐私；更新过程有下载进度/取消和系统安装确认。

## C. 共用壳层

```text
[状态栏]
[返回 ←] [页面标题 + 当前路由器] [刷新/更多]
[重要状态 / 关键指标]
[筛选、搜索或一级分段]
[列表 / 卡片 / 图表 / 表单]
[固定操作区（仅编辑类页面）]
[五底栏（主工作区；详情可保留或隐藏，但后退一致）]
[系统手势安全区]
```

**禁止**单独给同一功能再做一套外观不同的“插件页”，应基于共用 Card / State / ActionBar / InlineFeedback / RiskConfirm 组件复用。
