# 变更记录（2026-11-14）

## 联网监测

旧实现 `processAllStatusData()` 使用 `c.slice(0,3)` 将监测实例截为前三项，并以 `+N` 概括剩余实例。详情页将全文放在一个双列 `detail-row` 中，手机上名称和状态挤成一行并截断。

新实现：
- 保留所有 `c.instances`，映射至响应式 `systemStatus.internetDetectorItems`。
- 新增 `internetDetectorSummary` 用于汇总 `正常数 / 总数`。
- 单独的纵向区域呈现所有监测目标；每个目标占据一行，名称可换行、状态不换行，采用独立颜色标识。
- 无实例、读取失败情况回退到简短状态文字。

## 签名

以先前已签名安装包为基础，证书 SHA-256 始终固定。密钥应通过 GitHub Secrets 注入，不直接提交。

## 构建范围

编译后的 `app-service.js` 在 `src/www`；`vendor/base.apk` 提供 Android/uni-app 原生运行时。这不是 Android 原生源码工程，也不是原始 Vue 工程。


## Material UI v0.5.9（2026-11-14）

- 应用子页面（进程、启动项、路由表、网络唤醒等）隐藏父级通用刷新按钮，避免同时出现两个刷新图标且刷新范围不明确。
- 子页面仅保留标题栏右侧的“刷新当前功能”，调用当前子应用的数据加载逻辑；返回应用功能列表后，父级刷新按钮恢复。
- 增加 UI 自动化回归断言，验证子页面只有一个刷新按钮、返回列表后恢复父级刷新按钮。


## Material UI v0.5.10（2026-11-14）

- 网络页“接口 / 设备 / 无线”分类卡片改为三列单行排列，不再占用两行。
- 缩小网络分类卡片高度、图标和内边距，保留分类名称、数量及选中态；窄屏进一步压缩尺寸，避免横向溢出。
- 样式仅作用于网络分类区域，不改变终端页原有的 2×2 分类宫格。
- 增加 Playwright 回归检查，确认三个网络分类卡片处于同一水平行且高度符合紧凑布局。


## Material UI v0.5.11（2026-11-14）

- 首页“以太网接口”由纵向表格式列表改为网口图标 + 接口信息卡片，左侧突出网口图标和连接状态，右侧展示接口名称、实时 RX/TX 速率及累计收发流量。
- 保留原有接口数据来源、连接状态判断和流量统计逻辑，仅调整展示结构与样式。
- 针对窄屏优化卡片间距、图标尺寸和流量文字布局。
- 增加 Playwright 回归检查，验证网口图标、连接状态、RX/TX 与累计流量均正常显示，且旧表格行结构已移除。
