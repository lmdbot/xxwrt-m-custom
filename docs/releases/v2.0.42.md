# XX-WRT Material v2.0.42

## 新功能

- “设置 → 关于”新增应用品牌展示，使用当前 Android APP 启动图标的既有原始素材；版本标签可打开版本详情，查看安装版本、原生构建号、实际前端构建日期和包名，并可复制版本信息。
- 新增独立“隐私与免责声明”说明弹窗，介绍本机存储的路由器资料、Android 安全凭据存储、网络访问与更新服务、路由管理操作的安全风险。

## 优化

- 参考 NPatch 的信息分层，重新设计关于页面：居中应用图标和简介，按“应用信息 / 版本与更新 / 相关链接”组织入口，统一图标容器、点击反馈和留白，适配深色、浅色及窄屏。
- 保留现有阿里云优先、GitHub 备用的正式版本检查方式，继续提供下载与安装、进度展示、取消、重新打开安装和版本日志；项目地址、Issues 反馈及开源许可证复用原有功能。
- 关于页面新增英文翻译，繁体中文沿用现有本地转换，保持三种语言设置可切换；新增移动端自动化 UI 测试，覆盖图标加载、版本详情、隐私信息和许可入口。

## 修复

- 适配新版关于页面的版本展示与 Issues 无障碍名称，更新自动化用例对双位置显示版本号的检查逻辑。

## 注意

- 本次不修改 APP 包名、签名方式、Android 启动图标素材，也不改变 QWRT / OpenWrt 管理接口。
- 版本号提升至 v2.0.42，正式版 APK 仍由主线 GitHub Actions 编译、签名与发布；Android 安装仍需用户确认。
