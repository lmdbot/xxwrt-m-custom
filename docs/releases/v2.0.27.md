# XX-WRT Material v2.0.27

## 优化

- 发布用于验证 APP 从 v2.0.26 升级到 v2.0.27 的自动更新测试版本。
- 保持 v2.0.26 引入的 Android `PackageInstaller.Session` 安装流程不变，以便单独验证版本发现、阿里云 APK 下载、完整性校验及系统安装确认。

## 其他变更

- APP 版本从 2.0.26 更新到 2.0.27，Android `versionCode` 从 `2000026` 递增到 `2000027`。
- 本次不调整路由器管理功能、Android 安装模块实现、应用签名配置或阿里云更新服务的发布与保留规则。
- 正式版在 GitHub Actions 构建签名成功后发布到 GitHub Releases，并按现有流程同步到阿里云镜像。
