# XX-WRT v3.0.7

## 优化

- 概览状态卡片用“查看系统详情”及向下箭头替换难理解的右箭头；点击自动展开并定位。
- 概览 CPU、内存、温度、存储卡片打开对应详情行；终端跳转设备页签，联网监测仍打开 Internet Detector。
- 关于页移除顶部夹在版本和检查更新之间的复制图标；复制功能保留在版本详情弹窗。
- “关于 XX-WRT”现可点击查看应用版本详情。
- 检查到新正式版时，顶部提示直接提供“立即更新”按钮，无需滚动到底部。
- 我的快捷应用数量上限调整为 8 个，保留原有默认应用及用户收藏。
- 网络连接卡片的 LAN 区域显示 DHCPv4/DHCPv6 真实配置状态：开启绿色、关闭灰色、RPC 不可用显示未知。
- 默认网关、DNS、WAN6 有效期整合到网络连接卡片底部；物理设备、无线设备页移除重复的网络概览。
