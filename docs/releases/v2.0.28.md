# XX-WRT Material v2.0.28

## 优化

- 设备列表页面将“设备列表”标题上移至固定顶部导航栏，替换该页面原来的“我的 OpenWrt”顶栏标题。
- 将设备列表的“刷新设备状态”与“＋ 添加”按钮一同放到顶部导航栏右侧，与菜单和标题排成一行。
- 删除页面内容中重复占空间的设备列表标题及操作按钮区域，让在线状态筛选和设备卡片整体上移。
- 为 360px 等窄屏手机调整顶部按钮宽度与间距，保证“添加”文字可见，避免横向溢出。
- 增加 Playwright 回归检查，验证顶部标题、刷新与添加按钮的布局、唯一性和原有交互。

## 其他变更

- APP 版本从 2.0.27 升级到 2.0.28，Android `versionCode` 对应更新为 `2000028`。
- 保持设备筛选、设备卡片、编辑删除及现有检测刷新逻辑不变；不影响路由器管理业务和 Android 自动更新机制。
