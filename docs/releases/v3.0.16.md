# XX-WRT v3.0.16

## 修复

- 修复「概览 → 存储」水位在手机左倾约 60°～70° 时，卡片右侧出现一块悬空的蓝色尖角的问题；同一修复也适用于 CPU/内存水位。
- 原因是 `clip-path: polygon(...)` 斜线水面与两个独立的椭圆波纹遮罩在大角度倾斜时相互穿插，产生不连续的三角形区域。
- 改为**一条连续的 SVG 贝塞尔曲线液面**，由同一个 SVG `path` 同时绘制完整水体与流动波纹，不再使用会交叉的 CSS 挖空伪元素。
- 重力倾斜、上下晃动、惯性回弹和轻微波浪继续有效；水位中线仍与真实 CPU、内存、存储百分比一致。
- 保留浅色/深色模式对比度、文字层级和系统减少动态效果支持。
- 增加 18% 低水位、左右最大倾斜、纵向振动及异常传感器输入时的曲线完整性回归。
