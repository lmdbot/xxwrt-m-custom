# XX-WRT Material v2.0.41

## 优化

- 参考 Material 的交互模式，将页面动效从简单入场补充到导航过渡：五个底栏页签、设备列表/详情、设置分类与应用子页面按进退方向进行轻位移、缩放和淡入，约 270ms；保持组件挂载以免影响页面滚动、输入和路由器 RPC。
- 增强终端、网络分类切换动效（约 210ms）；路由器列表增加筛选/排序/移除的位移动画；应用分类展开收起使用 Vuetify 展开过渡；常用应用、侧栏与列表项有限错峰入场。
- 导航选中图标增加短暂回弹反馈，应用图标、分类按钮、常见开关增加按压过渡，鼠标 Hover 抬升仅在支持精细指针的设备启用。
- 动画主要使用透明度和 transform，不对实时流量、CPU、长期趋势样本等数据轮询重播页面动画；大设备列表限制首批动画数量。
- 继续沿用“设置 → 显示 → 界面动效”开关，系统 prefers-reduced-motion 优先。关闭开关后取消正在播放的原生 Web Animations，所有浮层的动效也保持统一关闭。
- 补充进退场分类、动效时长、取消和开关行为的自动化回归测试。

## 注意

- 动效不影响防火墙、QoS、DNS 等管理操作及返回/滚动位置语义；不代替真实操作状态提示。
- Android 系统文件选择器、安装确认等外部页面的动效仍由系统本身控制。
