# XX-WRT v3.0.13

## 新功能

- 概览页 CPU、内存、存储的动态水位新增**重力与晃动响应**：手机左右倾斜时，水面随之倾斜；晃动产生惯性回弹，并渐渐恢复平静。
- 水位平均高度仍严格对应实时使用率，手机动作只改变水面形状；0% 不出现水面，100% 不出现空白。
- Android 原生通过系统重力和线性加速度传感器采样，约 30 Hz 上限，不需危险权限。构建时自动注册原生插件；网页端在浏览器支持且授权时以 DeviceOrientation / DeviceMotion 作为退化方案。
- 仅路由器已连接、概览页在前台可见、开启应用动效且系统未要求减少动态效果时启动监听；切换页面或退后台立即停止监听与动画，节约电量。
- 沿用深浅模式已有的水色和高对比文本，波纹动效仍保留；没有传感器的设备静态显示真实百分比。
