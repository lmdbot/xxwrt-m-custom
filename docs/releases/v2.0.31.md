# XX-WRT Material v2.0.31

## 修复

- 修复 Android 系统返回手势在“网络 → 接口 → 配置网络接口”弹窗打开时，直接跳回设备列表的导航问题。
- 返回手势、顶部返回按钮现在优先关闭接口配置弹窗，保留当前路由器的网络页面；不执行任何网络配置写入。
- 网络配置已经提交但尚未确认保留时，返回手势会被拦截，并提示先“确认保留配置”或“立即回滚”，避免绕过 90 秒自动回滚保护。
- 网络接口连接/断开确认弹窗同样优先响应返回操作。
- UI 回归测试覆盖 LAN/WAN 配置弹窗的返回行为以及网络配置待确认时的返回阻断。

## 其他变更

- 版本号由 2.0.30 升至 **2.0.31**，方便已安装 2.0.30 的用户检查更新并下载安装修复版本。
- 不改变 UCI 接口配置和 DHCP 功能逻辑，仅修复弹窗与 Android 返回导航的交互。
