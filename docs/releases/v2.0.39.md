# XX-WRT Material v2.0.39

## 修复

- 修复从日志中心、设置等子页面返回时，应用列表丢失原有纵向滚动位置的问题；根据设备和页面分别保存滚动位置，在返回时恢复。
- 修复长期趋势在 24 小时宽时间窗内只有少量采样时，所有数据点被挤在图形右侧的问题；视图聚焦实际采样区间，不伪造历史样本。
- 修复恒定 0% 等平稳指标只能贴着图表底线的问题，并断开长期无采样的折线。

## 优化

- 按用户反馈移除设备拓扑功能及其相关入口、数据采集和旧拓扑页面。
- 重做长期趋势图表：放大折线、渐变填充、可读的时间刻度、单点标记、最低/平均/最高统计及采样说明。
- 扩展安全分析为「安全与运行日志分析」：新增七类基于真实日志的安全线索及运行异常规则、日志级别概况、日志来源状态、常见系统模块活跃度、实际警告/错误摘录。
- 规则匹配次数为 0 时仍展示已有日志的概况和规则说明，不把未命中解读为没有安全问题。
- 增加稀疏趋势、历史缺口、安全分类与日志摘要测试，并更新应用入口测试。

## 注意

- 长期趋势仍仅保存当前 APP 连接期间采集的真实样本，本次没有增加路由器常驻后台采集服务。
- 安全分析不运行主动扫描、不提供入侵归因。只有路由器实际记录并允许读取的日志能用于本次分析；防火墙规则日志通常需要单独启用。
- 本次不修改路由器配置，也不会清除用户本机已有监控记录。
