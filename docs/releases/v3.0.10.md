# XX-WRT v3.0.10

## 新功能

- 实验室新增 5 项可实际使用的实验功能：自定义刷新策略、自定义概览卡片、RPC 脱敏诊断、备用连接入口智能切换、高级网络健康检测。不加入智能异常提醒。
- 刷新策略支持省电/均衡/实时/自定义配置，修改后刷新定时器即时生效，同时在后台隐藏时减少无效采样。
- 概览支持针对不同路由器调整六张指标卡片的顺序和显示状态，至少保留一张卡片。
- RPC 调试只记录接口名、调用耗时和结果，不记录账号、URL、请求或响应正文；关闭时立即清空。
- 智能连接切换仅接受用户明确输入的受限地址，配对及切换都验证稳定设备身份，失败保留现有连接。
- 网络健康检测展示 WAN/WAN6/网关/DNS/Internet Detector 状态；主动检测只针对已有网关/DNS 地址执行有限 Ping。

## 优化

- 实验室新增「恢复默认值」入口及二次确认：恢复均衡模式与默认概览布局、关闭全部实验开关、清理 RPC 日志和各路由器的备用入口配对，保留常规设置、保存的账号和当前连接。


### 概览资源卡片水位动效

- CPU 占用、内存占用、存储三张卡片增加从底部按真实百分比填充的动态水位和轻微双层波纹；原有点击跳转及三列布局不变。
- 支持浅色与深色主题，标签和数字固定覆盖在水位上方，水位较高时仍保持可读性。
- 开关遵循“界面动效”设置及系统“减少动态效果”偏好，关闭动效时保留静态真实水位。
- 未读到有效百分比时不显示水位，避免把未知值误写成 0%。
