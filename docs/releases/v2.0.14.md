# XX-WRT管理器 v2.0.14

## 新功能

- **Lucky 应用管理：** 在 QWRT 应用列表新增 Lucky，展示核心状态、运行状态、版本、架构和后台配置摘要；支持启动、停止、重启以及意外退出自动恢复开关。
- **Lucky 访问规则：** 原生编辑 `ip-allowlist.txt`（绝对 IP 白名单，Lucky 3.1.0+）与 `localips`（局域网网段），支持读取、修改、保存、恢复默认内网段及 64 KiB 限制。使用 Lucky LuCI 官方临时工作区与服务端规则校验，避免直接猜测文件路径。
- **Lucky 维护入口：** 显示核心执行权限状态并可修复。整目录备份/恢复、内核升级和清空配置等高风险文件操作通过一键打开官方 LuCI 完成，保留其上传校验和服务恢复流程。
- **Lucky 异常日志：** 新增“最近异常退出日志”，调用插件提供的诊断助手，展示 logread / dmesg 中与 Lucky 异常终止相关的有界摘要。

## 优化

- **SSR Plus+ 节点切换：** 优先调用 OpenWrt `rc.init` 官方服务重启接口，在授权不足时回退现有执行方式；操作后读取 UCI 验证节点是否保存。
- **错误反馈：** 明确区分“节点配置已保存”和“服务重启已确认”。对于权限不足或重启状态未知的场景，用黄色提示说明待确认，不再将成功的 UCI 保存误报为整体失败。

## 修复

- **SSR 误报警：** 修复“应用节点并重启”在已保存配置后因 `file.exec` 重启权限不足显示红色错误的问题。
- **初始化与回归：** Lucky 访问规则改为串行加载，避免初始化过程中的并发锁冲突；新增 Lucky RPC、临时令牌和规则保存的单元测试。
