# XX-WRT v3.0.11

## 修复

- 修复「设置 → 实验室 → 自定义应用图标 → XX-WRT M 经典版」图标发虚的问题。
- 将之前从旧版 APK 提取的 72×72 `static/logo.png` 替换为从 `v1.0.6` 原始 `vendor/base.apk` 提取的 **192×192** `res/drawable-xxxhdpi/icon.png`，直接保留原始像素，不通过低清图片拉伸生成。
- 应用内图标预览、Android 桌面图标与 Android 自适应图标前景使用同一套高分辨率素材；更新原始图片 SHA-256 校验，阻止误回退为低清图。
- 当前二次元默认图标、OpenWrt 标识图标及自定义上传功能保持不变。
