# XX-WRT v3.0.23

## 优化

- 路由器登录并进入「概览」后，**自动定时刷新「设备」页的终端列表**，无需先切到设备页；停留在设备页时也持续更新。
- 复用现有设备刷新档位：均衡模式默认每 15 秒、省电模式 30 秒、实时模式 10 秒；自定义档位随设置生效。
- 自动刷新强制获取最新 DHCP 租约、无线关联终端与应用过滤用户数据，不受首次加载的 45 秒缓存限制。
- App 位于后台、离开路由器详情、打开设置或停留在无关页面时暂停自动轮询；单次请求仍在进行时跳过该周期，避免重复请求。
- 自动刷新失败时保留最后一次成功获取的设备数据，后续周期继续重试；手动刷新仍会强制重新请求。

## 验证

- 更新 Android 尺寸 Playwright 回归：单路由器登录进入概览后，即使从未打开设备页，仍能观测到下一轮真实 DHCP 租约请求；此前手动刷新回归继续保留。
