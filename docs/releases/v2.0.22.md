# XX-WRT Material v2.0.22

## 优化

- 将 Lucky 页面读取 `ip-allowlist.txt`、`localips`、保存规则及维护操作的成功与失败提示统一调整为底部悬浮提示，不再在页面顶部显示操作结果横幅。
- 将 Vlmcsd KMS 服务器的保存、应用、恢复及读取错误提示改为底部悬浮提示；运行状态继续保留为页面内状态信息。
- 排查并统一主应用设备列表错误、版本更新与 APK 下载反馈、进程/启动项/路由表读取错误、微信推送相关操作错误的反馈方式；必要的运行状态、无数据说明和安全告警仍保留在功能区域。
- Vlmcsd KMS 服务器「配置文件」页签输入框由 15 行缩减为 6 行，取消自动撑高，长文件在输入框内滚动。
- 删除 Vlmcsd 与 Lucky 页面内部重复的刷新按钮，保留顶部工具栏的统一刷新入口；Vlmcsd 存在未保存修改时，顶部刷新将阻止覆盖并提醒先保存或复位。

## 修复

- 修复设备地址校验与登录错误同时出现在弹窗内和悬浮提示中，导致 UI 测试定位重复文本失败；统一仅使用悬浮提示。

- 移除 Android 正式发布工作流中已弃用的 Webhook 发布通知步骤，避免通知接口返回 HTTP 403 导致已成功发布的 APK 构建被误标为失败。
- 不影响 GitHub Releases 自动发布、阿里云 Lucky 静态更新服务、版本信息生成、APK 签名和服务器最新 5 版 APK 保留策略。

## 其他变更

- 应用版本更新至 2.0.22，支持已安装 2.0.21 的用户检查升级。
- 发布通知改为由阿里云服务器自行监测更新文件变化，工作流不再发送 Webhook。
- UI 提示、输入框和刷新入口调整均不改变路由器 UCI、ubus/RPC 接口与服务配置。
