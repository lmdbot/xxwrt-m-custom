# XX-WRT v3.0.17

## 界面优化

- 网络页顶部取消独立的「网络连接」标题和包裹 WAN/LAN 的大型蓝色容器，直接展示 **外网 WAN** 和 **内网 LAN** 两张独立卡片。
- WAN、LAN 每张卡片均使用单层背景和边框；取消内部深色卡片的二次边框与圆角，仅保留字段间的细分割线，降低深色模式下的视觉嵌套层级。
- 适度优化标题、状态标签、字段间距及 390px 以下手机屏幕的横向空间，改善长 IPv6 地址和多 DNS 服务器的可读性。
- WAN IPv4、WAN6 IPv6、WAN/WAN6 连接时长、网关、DNS、WAN6 有效期，以及 LAN IPv4、DHCPv4、DHCPv6 状态全部保留。
- 「接口与连接」和「网络服务与策略」下方入口及业务逻辑不变；仅调整布局，不增加网络 RPC 请求。
