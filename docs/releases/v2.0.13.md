# XX-WRT管理器 v2.0.13

## 新功能

- **微信推送设备别名：** 新增独立“设备别名”页面，支持添加、修改、删除、批量编辑与保存，可从在线设备列表一键带入 MAC/IP 地址。直接兼容 QWRT 微信推送插件的 `/usr/share/wechatpush/api/device_aliases.list`。
- **保存冲突防护：** 写入前检查路由器上的别名文件是否被其他页面修改，避免覆盖他人的更新；别名文件独立保存，不重启微信推送服务。

## 优化

- **中文运行时间：** 首页和 OpenWrt 设备列表共享中文时长格式，根据实际值显示“天 / 小时 / 分钟 / 秒”，不再出现 `1d 22h 15m` 等英文缩写。
- **兼容性：** 保留设备别名文件中的注释和空行，并检测重复地址、缺失别名以及超大文件。

## 修复

- **回归测试：** 增加设备别名处理和中文在线时间格式化的自动化测试，纳入 Android 构建前的逻辑测试。
