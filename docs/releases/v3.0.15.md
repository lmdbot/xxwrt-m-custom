# XX-WRT v3.0.15

## 修复与优化

- 修复「概览 → CPU/内存/存储水位」手机摇动时反馈过于微弱、约 18% 水位几乎看不出动作的问题。
- 原实现只对左右方向加速度做有限的水面倾斜，视觉最大单侧坡度 8px，且水色较浅；新版提高至 14px，并保留较平滑的惯性回弹。
- 新增上下/前后晃动触发的瞬态液面起伏（最多约 5px），即使只上下摇动也能看到水的波纹，而不仅依靠手机左右旋转。
- 提高深浅主题的水色对比，但文字仍固定为高对比色；低水位采用扩展裁切区域，18% 水位获得完整晃动响应。
- Android 优先使用重力和线性加速度传感器；若设备没有线性加速度传感器，则从普通加速度传感器推导动态分量，避免彻底失去晃动效果。
- 摇动时只修改实际水面元素的 CSS 变量，避免数据刷新时清理传感器动态样式；真实 CPU、内存、存储占用百分比保持不变。
- 继续尊重界面动效和系统减少动态效果开关，页面隐藏、切换页签或离开应用时暂停传感器监听。
- 增加 18% 水位、纵向晃动、阻尼回弹纯逻辑检查，以及 Android 尺寸 UI 中模拟姿态/运动事件的水面样式行为回归。

说明：自动化测试验证数据流与渲染，真实手机传感器手感仍需安装 APK 后现场确认。
