# XX-WRT Material v3.0.0

## 新功能

- 整体重设计导航信息架构：正式五底栏“概览 / 设备 / 网络 / 工具 / 我的”，Material 3 + 轻玻璃视觉样式，适配深浅主题及窄屏手机。
- 概览加入网络健康摘要、CPU/内存与客户端指标、真实实时流量预览，以及接口、防火墙、DDNS 和网络诊断快捷操作；原“统计”调整为从概览进入的独立详细监控页。
- 设备页面加入家长控制与网络唤醒快捷入口；网络页面新增接口、物理硬件、无线、路由表、DNS/DHCP、防火墙、DDNS 和 ZeroTier 的集中功能入口。
- 工具中心采用原有每台路由器五项收藏与搜索能力，并按插件中心、系统管理、诊断与安全、维护与备份重新分类；“我的”集中路由器管理、应用设置和关于更新。

## 优化

- 页面标题、主路由器切换、页签导航和详情返回采用统一逻辑，避免进入网络/终端功能时回到错误位置。
- 保留所有已有 28 项管理工具及现有 RPC/UCI 服务实现、插件能力识别、异常提示和软件包功能。
- 保留 IPv4/IPv6 网络配置的确认/回滚、路由器备份恢复二次确认、Android Keystore 凭据保护、升级下载安装与阿里云/GitHub 正式更新源。
- 单独引入 v3 样式层：更明确的分区层级、卡片密度、状态颜色和无障碍触控范围。

## 其他变更

- 升级安装包版本为 3.0.0（Android versionCode 3000000）；Android 包名及签名机制不变。
- 这是主线合并前的重设计候选版本；正式 APK 仅由主线 CI 全部验证成功后发布。
