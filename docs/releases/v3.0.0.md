# XX-WRT 3.0.0 — Material 3 + 轻玻璃重设计

## 3.0 全新信息架构
- 底部导航从六项调整为五项：**概览、设备、网络、工具、我的**。
- 原“统计”改为概览中的**详细监控**入口，保留原有实时采样与长期趋势。
- 概览新增实时流量简图与网络接口、防火墙、DDNS、诊断快捷操作。
- 设备页新增家长控制和网络唤醒的直接入口，保留原有终端、DHCP、QoS/HQoS 管理。
- 网络页增加路由表、DNS/DHCP、防火墙、DDNS、ZeroTier 分类快捷入口，保留接口、物理设备和无线数据。
- 工具中心按插件中心、系统管理、诊断与安全、维护与备份重新分类，保留每台路由器的五个常用工具及旧收藏数据。
- “更多”调整为“我的”，聚合路由器管理、应用设置和关于更新。

## 视觉体验
- 均衡信息密度的 Material 3 卡片、适度半透明的状态表面。
- 继续支持浅色、深色、系统跟随、原有液态导航设置和减少动态效果。
- 保留原生 Android 安全存储、版本更新、配置确认/回滚及危险操作确认。

## 兼容性与迁移
- 保留现有路由器信息、凭据、插件收藏、隐私及语言设置。
- 本次改造不修改路由器端配置或 RPC 业务协议。

> 3.0 正式发布前必须通过所有 Android UI、业务逻辑与 APK 签名回归测试。
