# XX-WRT管理器 v2.0.15

## 新功能

- **Vlmcsd KMS 应用：** 在路由器应用列表中新增 Vlmcsd KMS 服务器管理入口，显示服务运行状态。支持“启用 Vlmcsd KMS 服务器”“允许自动激活客户端”“允许来自互联网的连接”三个与 LuCI 相同的开关，并通过 UCI 保存。
- **Vlmcsd 配置文件：** 读取并编辑 `/etc/vlmcsd.ini`，提供“保存”“保存并应用”“复位”；限制最大写入 256 KiB。路由器未开放文件写入或服务控制 RPC 时明确提示，不假报操作成功。
- **WAN6 剩余有效期：** 在网络概览和 WAN6 接口卡片显示 IPv6 前缀或地址的剩余有效时间，格式按天、小时、分钟、秒自适应；路由器不返回有效期时不显示。
- **自签名 HTTPS 路由器登录：** Android 登录页新增“忽略此路由器 HTTPS 证书错误（不安全）”，同时可在设备编辑中管理。默认关闭，仅对明确选择的 HTTPS 路由器 RPC/LuCI 请求生效，不修改全局系统证书验证或其他主机的请求行为。

## 安全与兼容性

- TLS 例外使用 Android 原生的**单请求**连接配置，不跟随重定向，仅允许访问本路由器的已知 RPC/LuCI 路径。启用时有风险提醒；切换设备地址将清除旧证书例外。
- 支持使用 Android Keystore 独立保存设备密码；TLS 例外开关按设备保存，但不会保存明文密码。
- Vlmcsd 对配置读写和服务重启分别确认，避免在权限不足时误判操作成功。
