# XX-WRT v3.0.20

## 新功能

- 「添加路由器 / 编辑路由器」统一为单个登录配置界面，集中设置**路由器名称、主 IP/域名、端口、登录用户名、密码、HTTPS 证书选项**，以及最多 5 个备用登录 IP 或域名，不再需要先添加再分别配置密码与备用入口。
- Android 上的密码仍只存放在系统 Keystore 加密安全存储中；编辑时密码留空表示保留旧密码，更改主地址或用户名时要求重新配置才能继续保存自动登录能力。网页预览版不持久化密码。
- 备用地址支持可信 HTTPS 域名或私有 IPv4 HTTP；未填写协议的私有 IPv4 自动使用 HTTP，域名自动使用 HTTPS。输入校验防止带账号密码、查询参数、路径或公网明文 HTTP。
- 登录配置中提供「主入口失败时自动切换已验证的备用入口」开关；备用地址登录成功后会使用当前短期 RPC 会话确认路由器硬件身份，**未通过验证的入口不能接收自动切换请求或保存的密码**。
- 支持每台路由器配置多个备用登录入口。自动连接优先主地址；主地址出现网络故障后，仅对之前经过相同硬件身份验证的备用入口尝试重连。
- 已连接路由器的编辑界面保留原实验室的「重新验证已保存入口」和「切换至此」功能，支持在统一登录配置中按需验证或手工切换已验证的备用入口。
- 已有路由器、已保存的加密密码及实验室旧版单一已验证备用入口兼容保留。用户编辑路由器时也会看到以前配对的备用地址。

## 优化

- 从实验室页面移除「智能连接切换」卡片及相关配置入口，相关选项统一集中到路由器的「登录配置」中。
- 「恢复实验室默认值」不再清理路由器登录备用地址与已验证入口，避免误删核心连接设置。
- 登录弹窗保留临时输入密码的能力，但不再重复显示 TLS 和加密保存选项；需要长期保存密码或设置备用地址时可直接进入「登录配置」。
- 使用独立身份验证缓存区分多台路由器，只有用户明确填写、验证身份一致的备用入口才可用于自动连接；密码及短期 RPC 会话永不进入普通本地配置文件。
