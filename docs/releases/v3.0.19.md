# XX-WRT v3.0.19

## 新功能

- 应用启动时对已经保存并允许记住密码的路由器自动恢复认证会话，在**连接成功后立即预加载概览页和设备页数据**，无需先进入对应页面再等待首次采集。
- 路由器管理页可并发检测多台已保存路由器；每台已认证的设备独立预加载概览实时信息、磁盘/网口/DHCP 状态，以及终端 DHCPv4/v6、WechatPush 自定义名称和在线状态、Wi-Fi 关联设备、OpenAppFilter 用户。
- **仅保存一台路由器时**，APP 启动后自动尝试连接并直接进入概览页；如果尚未保存密码，自动弹出路由器登录框，需用户输入密码后再进入，不跳过身份验证。
- 有多台路由器时仍显示「路由器管理」列表；已连接设备的概览/终端数据存放在内存中的每路由器独立缓存，选中设备时优先直接显示预加载内容，避免因切换设备造成空白等待。
- 预加载数据仅存放在当前 APP 进程内，按路由器 ID 和已认证会话隔离，不持久化终端设备信息或密码；连续切换时不混用其他路由器的信息。
- 对近期成功预加载的设备页数据进行短时去重，防止刚连上路由器又点「设备」立即重复 RPC 请求；进入页面时超过更新期限仍会重新采集，确保状态新鲜。
- 沿用 Android Keystore 加密凭据和现有 TLS 安全选项；未记住密码或认证失败的路由器只做可达性检测，不尝试绕过登录。

## 优化

- 关闭或编辑路由器、切换设备时清理对应预加载缓存；旧会话迟到的异步数据不会覆盖当前路由器的概览或设备列表。
- 新增单路由器自动进入登录流程、进入概览后终端预加载以及多路由器启动保持管理列表的功能回归。
