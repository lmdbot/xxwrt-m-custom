# XX-WRT v3.0.27

## 新功能

- “设备 → 终端”新增小米路由器配置入口，可输入局域网 IP 和管理密码，验证并保存。
- 通过小米 MiWiFi 本地 API 获取设备清单，按照 MAC 合并到现有 QWRT / WeChatPush 终端列表，补充 **2.4G / 5G / LAN** 接入类型。
- 添加小米终端来源筛选、手动刷新、连接错误提示及配置移除。已配置的小米数据随终端数据刷新一起获取。
- 兼容小米旧固件 SHA-1、新固件 SHA-256 登录流程，失效会话会重新登录。密码保存在 Android 安全存储中，不写入本地明文配置。

## 在线状态策略

- **小米路由器仅用于设备发现和接入方式，不作为在线状态依据。**
- 已安装 WeChatPush 时，每次刷新重新读取 QWRT 上的设备监控文件；由 WeChatPush 明确的 online/offline 状态决定，监控不可用显示“待确认”。
- 未安装 WeChatPush 时，延续 QWRT 原有邻居表和 Wi-Fi 关联判定，不使用 DHCP 租约或小米在线标志推断在线。
- 不在线但有小米接入记录的终端显示“曾接入”；小米与 QWRT 设备通过 MAC 合并，不以 IP 强行归属。

## 验证与限制

- 新增小米设备连接类型解析、MAC 去重和在线状态隔离逻辑测试。
- 小米本地接口兼容性仍需通过 BE6000 / Redmi AX3000 真机验收；仅支持手机可以访问的 RFC1918 私有 IPv4 管理地址。
