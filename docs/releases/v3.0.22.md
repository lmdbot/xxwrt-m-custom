# XX-WRT v3.0.22

## 优化

- 将「添加 / 编辑 OpenWrt 设备」从长篇单页表单改为简洁的**两步式向导**，减少首屏信息密度，保持现有深浅主题与窄屏滚动能力。
- **步骤一「基础信息」**：设备名称、主地址、**备用入口（可选）**。备用入口明确留在第一步，最多 5 条；保留入口身份验证、已验证标签和手动切换操作。
- **步骤二「连接与安全」**：用户名、密码、Android Keystore 加密保存、自动切换备用入口及 HTTPS 证书配置。收敛过长的帮助文字，保留必要的 TLS 安全警告。
- 采用直观的 1/2 进度提示、「继续 / 上一步 / 保存设备」按钮及简洁的已填地址摘要；往返步骤时保留当前表单数据。编辑设备与新建设备复用同一流程。
- 第一步先进行名称、主地址和备用入口格式校验，再进入第二步；最终仍使用原有安全存储与已验证备用入口配对逻辑，不改变登录与自动切换安全策略。

## 修复

- 避免用户尚未完成全部两步就提交半成品路由器配置。
- 关闭编辑弹框时清除未保存的明文密码并重置当前步骤，重新打开从第一步开始。
