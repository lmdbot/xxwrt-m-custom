# XX-WRT v3.0.25

## 修复

- 设备页与概览页自动刷新、手动刷新统一读取 **当前路由器** 的 `/tmp/wechatpush/devices.json` 和设备别名文件。检测到 WeChatPush 已安装后，终端页不再使用 45 秒应用预加载缓存跳过刷新。
- 删除 v3.0.24 对历史 WeChatPush 在线状态/名称长达 90 秒的回退，读取失败、数据无效或服务明确停止时不再显示上一次缓存的在线状态或备注。
- 对 WeChatPush 运行状态的可选 RPC 更宽容：若状态接口无法返回可靠信息，但**本次**设备文件读取有效，则允许正常使用文件内的在线状态；明确停止时不将旧文件误认作实时状态。
- WeChatPush 监控不可用时，设备页展示告警并将在线/离线统计标记为“—”，终端状态显示“待确认”，避免误报“在线 0”；正常读取恢复后立即采用最新状态。
- 已安装 WeChatPush 时，DHCP、邻居表、无线关联和 AppFilter 仅提供补充资料，不再覆盖 WeChatPush 的明确在线/离线状态。未安装插件的路由器仍可使用原有判定机制。

## 验证

- 回归测试涵盖：首次读取有效文件、服务状态接口无响应、明确停止服务、无效 JSON、刷新后状态/名称变化、错误时不复用历史状态、45 秒缓存内重新进入设备页发起新 RPC。
- 注：`devices.json` 是 WeChatPush 在路由器上维护的最新监控快照。App 每次都重新读取它，但它的生成频率由 WeChatPush 自身决定，并非 App 实时扫描全部终端。
