# XX-WRT Material v2.0.35

## 修复

- 修复“配置备份与恢复”功能在 Android WebView 中只有 JSON 文本预览、通过 Blob/分享接口无法可靠保存文件的问题。
- 改用 Android 原生系统文档选择器（ACTION_CREATE_DOCUMENT）：选择目录和文件名、完成实际写入后才提示保存成功；取消保存或写入失败均不会误报成功。

## 优化

- 将主按钮改为“生成并保存 JSON”，同时保留“保存 JSON 文件”和“复制 JSON”功能，可重复保存同一次快照而不必重新读取路由器。
- 安卓保存文件无需申请存储权限，文件写入原始快照内容，不上传远端服务。
- 配置文件名、内容与 2MB 大小上限经过校验；增加原生插件生成校验和 Node.js 自动化测试。

## 其他变更

- 保持前一版的 DDNS、OpenClash、防火墙、Cron、监控趋势及操作审计等功能不变。
- 此快照仅包含所选 UCI 配置，不属于 sysupgrade 全量备份；可能含 PPPoE、Wi-Fi 等敏感认证参数，请注意文件保管。
