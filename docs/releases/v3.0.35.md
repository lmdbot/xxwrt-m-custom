# XX-WRT v3.0.35

## 修复

- 修复 v3.0.34 Android APK 构建失败：Playwright UI 用例仍期望“仅存在于微信推送离线历史记录”的终端出现在列表中，与新设备列表策略冲突，导致 29 项通过、1 项失败、APK 发布作业被中断。
- 更新测试断言，按当前有效业务规则验证：**设备列表 = QWRT 实际检测到的设备 ∪ 微信推送在线设备**，微信推送离线历史记录和小米历史设备不单独增加终端。
- 增加“仅微信推送在线、但没有 QWRT DHCP 租约”的设备测试，验证正常进入列表；一旦微信推送离线或数据失效就退出列表。
- 微信推送数据不可用时，必须清除历史监控状态及别名，但仍按 **QWRT 最新 REACHABLE / FAILED 邻居信息**显示在线或离线，不能因为监控故障把 QWRT 在线设备判成待确认。
- 微信推送报告离线、但 QWRT 判断在线且小米没有明确离线证据时，仍按 QWRT 在线状态显示。
- 仅更新与新策略冲突的 UI 回归测试及版本说明；不恢复旧的离线终端显示规则，不修改 QWRT、小米转发接口或在线判定业务逻辑。

## 验证

- APK CI 将重新运行包含 Android 构建、逻辑测试和 Playwright UI 回归检查的完整工作流。
- 现有 v3.0.34 业务规则保持不变，v3.0.35 用于修复构建发布阻塞。
