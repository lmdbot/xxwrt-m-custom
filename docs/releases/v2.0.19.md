# XX-WRT Material v2.0.19

## 新功能

- 应用管理首页新增“常用应用”快捷区：默认 5 个常用工具 + 1 个“全部应用”，支持编辑、增删、调整显示顺序。
- 常用应用按已保存的路由器独立保存到 Android 本地，重新进入后保持偏好；新增按应用名称、功能描述和分类搜索。

- ZeroTier 管理页面新增“网络接口信息”：展示接口名称、MAC 地址、IPv4 地址、IPv6 地址、最大传输单元（MTU）、总下载和总上传。
- 按 ZeroTier 虚拟网卡分别展示接口数据，支持多网络场景。流量使用 B、KiB、MiB、GiB 等单位自动换算。
- 通过 OpenWrt LuCI 与 netifd 的只读 RPC 获取网络接口及收发统计；缺少地址或统计时按权限尝试只读接口回退，无法获取的数值明确显示“未获取”。

## 优化

- 将应用入口整合为“网络与安全、服务与插件、系统工具、设备维护”四个默认折叠分类，三列常用快捷入口固定在两行内。
- 自动隐藏当前路由器未安装的插件；重启设备、恢复出厂不允许放入常用应用，原有二次确认流程保持不变。
- 补充应用分类、常用编辑、搜索、多设备偏好隔离和危险操作保护的 UI / 单元回归测试。

- 侧边栏设置分类统一在顶部导航栏显示当前页面标题，移除内容区重复的标题和返回按钮，提升手机端可用空间。
- ZeroTier 接口信息采用适配窄屏的双列布局，IPv6 地址可完整换行显示。
- 补充新界面的英文翻译，以及接口地址、MTU、流量计数器和返回导航的自动化回归测试。

## 修复

- 避免将 ZeroTier 状态 RPC 不可用误判为网络断开；区分虚拟接口启用状态与网络连接状态。
- 未取得接口流量计数器时不再将缺失值误显示为 0；真实零流量仍显示 0 B。

## 其他变更

- 本次应用入口优化仅变更 Android 界面和本地偏好，不修改路由器侧插件、UCI 配置或网络规则。
- 接口信息采集是只读操作，不修改 ZeroTier 网络配置、路由规则或设备权限。
- “总下载/总上传”来自路由器网卡累计收发字节计数器，并非实时速率。
