# XX-WRT Material v2.0.36

## 新功能

- 配置备份与恢复增加与 LuCI 相同用途的**系统原生配置归档导出**，使用路由器现有的 /cgi-bin/cgi-backup 和登录 Session，生成 tar.gz 并通过安卓系统另存为窗口保存。
- 新功能与原有 UCI JSON 快照并列，原生备份包含 sysupgrade 备份规则选定的文件，不触发配置恢复、恢复出厂或固件升级。

## 优化

- 安卓原生插件流式接收二进制归档，在手机应用私有缓存验证 gzip 完整性（CRC）后，写入用户通过系统文件选择器选定的位置。
- 对 64 MB 压缩包及 256 MB 解压上限进行保护；路由器权限不足、CGI 路由缺失或返回非 gzip 页面时拒绝保存并提示。
- 仅在用户明确为特定路由器启用 HTTPS 证书忽略选项时使用该连接的证书例外，不改变系统全局 TLS 配置。
- 保留 JSON 导出、复制及局部恢复流程，增加原生备份命名和权限校验回归测试。

## 注意

- 此 tar.gz 是系统配置文件的备份，不是 OpenWrt 固件镜像或磁盘完整克隆。
- 归档可能含宽带账号、Wi-Fi 密钥、插件凭据和 TLS 证书。HTTP 路由器通信属于明文传输，建议可信内网、VPN 或 HTTPS。
- GitHub Actions 构建测试不能代替路由器与安卓实机联调；CGI 接口需要目标固件提供且当前账号有权限。
