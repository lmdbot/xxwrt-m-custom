# XX-WRT v3.0.33

## 新功能

- **小米历史设备连接类型**：设备页同时通过 QWRT 查询 `misystem/devicelist` 当前记录，以及 `xqsystem/device_list?all=1` 历史记录，不再第一个接口成功后就停止。
- 根据 MAC 合并设备，当前记录优先，历史记录补充不存在的终端以及缺失的连接类型信息，支持 2.4G、5G、LAN 和无线（频段未知）。
- 离线、未知以及只有历史接入证据的终端卡片和详情，展示「曾接入 · 2.4G / 5G / LAN」，避免将最后一次连接信息描述成当前 Wi-Fi 状态。
- 小米数据来源标签改为「小米记录」，以免误解为每台终端当前均连接在小米 AP 上。

## 修复

- 兼容小米当前/历史设备列表可能出现的 `list`、`dev` 和 `data.list`、`data.dev` 响应，以及 `type: line` 有线连接。
- 当前接口和历史接口独立读取：一方失败时使用另一方的有效数据；两方失败时明确报错，允许既有 stok 重登流程处理。
- **在线状态不受小米影响**：小米历史 IP 不被当作当前地址，小米 `online` / `status` 不参与在线判断。WeChatPush/QWRT 仍是唯一的当前在线状态来源。
- 不在 Android 端持久缓存设备历史快照，每次刷新从已配置的小米设备读取，配置删除或失败时清除旧元数据。

## 验证

- 新增当前 2 台 + 历史 10 台、按 MAC 去重、类型优先级、缺失频段、单接口失败和双接口失败、历史在线标记隔离等回归测试。
- 无需重新安装 QWRT 端扩展：现有扩展已经放行 `xqsystem/device_list?all=1`，只需升级 App。
