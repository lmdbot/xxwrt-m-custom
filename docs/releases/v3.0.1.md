# XX-WRT Material v3.0.1

## 优化

- 严格沿用整体 UI/UX 方案 A 的五底栏：「概览 / 设备 / 网络 / 工具 / 我的」，Material 3 + 轻玻璃、均衡信息密度，不增设第六页或侧边栏。
- 「概览」展示真实 CPU、内存、存储占用以及 WAN、IPv6、在线终端网络摘要；简化实时曲线继续可以打开独立详细监控，无任何模拟指标。
- 「我的」与设计图一致收敛为路由器管理、应用设置、数据与隐私、帮助与反馈、关于 XX-WRT 五个常用入口；显示、隐私、刷新、实验室、语言保持在二级设置目录。
- 新增简洁的帮助与反馈页面，继续复用已有开源项目与 GitHub Issues 入口，保持原生 Android 返回层级。
- 保持全部现有路由管理和插件能力、RPC/UCI、隐私配置、升级安装、深浅主题与国际化；补充页面导航、窄屏、网络摘要和新版本检查的回归测试。

## 修复

- 修复新版本检查自动化测试的模拟版本号与本地版本相同造成的错误判定，改为使用相对于安装包的新版本。
