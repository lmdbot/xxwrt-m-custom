# XX-WRT Material v3.0.1

## 优化
- 在整体 3.0 方案 A 的基础上恢复独立的第六底栏「更多」，保留「概览 / 设备 / 网络 / 工具 / 我的」及已有全部二级页面。
- 「更多」只展示路由器、设置、关于三个入口；显示、隐私、刷新、实验室、语言归入设置二级目录。「我的」保留应用信息及常用设置快捷入口。
- 同步调整六底栏导航选中态、动效顺序、手机窄屏布局与 Android 返回逻辑，兼容标准/液态玻璃底栏和深浅主题。
- 增加六底栏、设置层级、语言及横向溢出的自动化回归检查。

## 其他变更
- 版本 3.0.1，Android versionCode 3000001；保留现有 28 项功能、RPC/UCI 处理、签名密钥与更新通道。
- 功能分支只生成测试构建，不发布正式 Release 或更新阿里云稳定源。
