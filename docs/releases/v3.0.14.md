# XX-WRT v3.0.14

## 优化

- 「设备 → 终端列表」与 WeChatPush 设备在线列表联动：如果安装了 WeChatPush，优先从 `/usr/share/wechatpush/api/device_aliases.list` 读取自定义备注名，按 MAC 优先、IP 辅助的规则匹配，名称优先级高于 WeChatPush 自动检测名和 DHCP 主机名。
- WeChatPush 服务实际运行时，采用 `/tmp/wechatpush/devices.json` 中对应 MAC 的 `online`/`offline` 作为设备在线状态；未运行、数据缺失或状态未知时回退现有邻居可达、无线关联判断，不把过期的 DHCP 租约视为在线。
- 连接方式根据监测字段 `type`、`interface` 及 `wlan` 频段映射显示：2.4G/5G 显示「无线 · 2.4G/5G」；LAN 或空值显示「有线」。只有设备在线时显示连接方式，不把历史记录当作当前接入状态。
- 微信推送在线设备即使没有 DHCP 租约，也可按 MAC 出现在终端列表；离线历史设备不会单独新增大量冗余卡片。
- 设备来源筛选新增「微信推送」，无线终端筛选和在线数量统一以合并后的实际终端数据计算。
- 未安装 WeChatPush 的路由器保持原有 DHCP、Wi-Fi、ARP/NDP、OpenAppFilter 数据逻辑，全部为只读查询。
