# XX-WRT Material v2.0.20

## 优化

- Android APP 启动器图标替换为已选定的蓝色二次元 Q 版 OpenWrt 路由器少女：保留猫耳少女、OpenWrt 路由器、双天线、Wi-Fi 信号和状态指示灯等核心视觉元素。
- 沿用主线原有图标生成脚本，在 GitHub Actions 每次新建 Capacitor Android 工程后自动生成 mdpi 至 xxxhdpi 的普通图标、圆形图标和自适应图标。
- 调整自适应图标背景为蓝色，并校验源素材 SHA-256，避免素材遗漏或被误替换。
- 更新应用版本为 2.0.20，使已安装的 2.0.19 正式版可以正常识别升级。

## 其他变更

- 本次仅调整 Android 应用图标资源和版本号，不改变页面结构、路由器 RPC、设备管理逻辑及已有用户配置。
