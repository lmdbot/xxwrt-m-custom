# XX-WRT v3.0.38

## 优化

### 终端卡片布局及背景色

- 重构终端卡片：设备名称与在线/离线状态在首行对齐，设备类型及 IP/MAC 置于正文，LAN/无线、DHCP、随机 MAC、来源和无线信号胶囊集中在同一个底部流式区域；空间不足时统一换行，不再在右上角堆叠漂浮标签。
- 所有信息胶囊与状态胶囊统一 22px 高、全圆角、11px 字号、8px 横向内边距与居中对齐。
- 取消卡片按压时的灰色底色以及 Vuetify 卡片的覆盖层反馈，避免个别终端短暂显示不同背景；保留焦点轮廓。
- 无线接入类型已明确时，不重复生成“无线”来源胶囊；无线信号未获取到数值时不显示空白 Wi-Fi 信号胶囊。
- 仅更改终端卡片展示；QWRT、微信推送、小米的采集、在线判断、设备集合和详情功能保持原样。
