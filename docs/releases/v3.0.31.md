# XX-WRT v3.0.31

## 修复 QWRT 小米 RPC 后端调用失败

- 修复 QWRT 安装自检提示“`The Xiaomi RPC method is registered but cannot be called`”的问题。
- 根因：小米 rpcd Shell 后端使用 `set -eu`，其中 `set -u`（nounset）与 OpenWrt 的 `jshn.sh` JSON 函数中未初始化的可选变量不兼容；执行 `Fetch` 时可能提前退出，导致 ubus 不返回正确 JSON。
- 后端改为 `set -e`，保持错误退出策略而不启用 nounset；不扩大 ACL、不开放 `file.exec`。
- 安装脚本的调用自检新增原始 `ubus` 错误与直接调用后端的诊断输出，用于区分 rpcd 路由问题和脚本执行异常。
- 新增 Shell 回归测试：模拟 `jshn.sh` 引用未定义全局变量，验证无效内网地址自检能正常返回 `{"code":400,"body":""}`，不再让 rpcd 返回服务端异常。

## QWRT 端升级

需重新下载安装仓库 `router/` 目录最新的 `luci.xxwrt-xiaomi` 和 `XX-WRT-QWRT-xiaomi-install.sh` 到 QWRT `/tmp`，以 root 执行 `sh /tmp/XX-WRT-QWRT-xiaomi-install.sh`。

安装成功应显示 `SUCCESS: QWRT has registered and executed luci.xxwrt-xiaomi.Fetch.`。随后重新登录 App 里的 QWRT，再验证小米路由器。

**注意：** APK 更新本身不会自动修改 QWRT 已安装的 RPC 扩展。当前修改不涉及用户小米密码及在线状态判定；实际 QWRT 固件仍需要现场确认执行结果。
