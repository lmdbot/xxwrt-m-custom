# XX-WRT Material v2.0.24

## 优化

- “设备列表”页面支持从屏幕左侧边缘向右滑动，直接展开现有的设置分类侧边栏，无需先进入已连接的路由器详情页。
- 复用设备详情页已有的边缘手势识别：必须从左侧约 72px 区域起滑、向右移动足够距离，避免把点击、上下滚动或页面中央横向滑动识别为打开侧边栏。
- 在添加/编辑设备弹窗、其他活动弹窗、设置页及侧栏已经打开时，不重复触发侧边栏，避免与当前操作冲突。

## 修复

- 关闭 Vuetify 侧栏自身的全屏触摸手势，统一由应用的左缘滑动识别接管，防止设备列表的普通横向滑动意外打开侧边栏，同时修复相关 Playwright 回归测试失败。
- 修复设备列表虽已有全局触摸监听，但被“已登录设备详情页”条件限制而无法通过右滑打开侧边栏的问题。

## 其他变更

- 应用版本由 2.0.23 升级到 2.0.24。
- 新增 Playwright 页面回归测试，覆盖未登录设备列表右滑、误触拦截、设备弹窗冲突和设置页面保护。
- 不修改路由器接口、设备列表数据、页面导航结构或其他更新下载功能。
