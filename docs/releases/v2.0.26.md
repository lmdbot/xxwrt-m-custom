# XX-WRT Material v2.0.26

## 修复

- 修复 Android 15/16 等部分系统上通过 APP 内更新时，APK 下载成功后由系统安装器提示“解析软件包时出现问题”的兼容性问题：不再将私有缓存里的 APK 通过 FileProvider URI 交给系统安装器，改为使用 Android 官方 `PackageInstaller.Session` 将安装包流式写入系统安装会话。
- 继续保留 APK 下载的白名单来源校验、大小、SHA-256、包名和版本号校验。只有通过检查的 APK 才能被提交系统安装会话；安装仍需用户在 Android 系统界面中确认。
- 对 Android 12+ 显式要求用户确认安装，通过应用内部广播接收器处理系统安装结果，并在系统安装失败时反馈状态码及具体原因，以便排查签名或 ROM 安全策略造成的安装失败。
- 安装会话的 APK 写入在后台线程执行，避免阻塞主界面。保留用户首次授权「允许安装未知应用」及授权返回后继续安装的能力。

## 优化

- Android 安装提示调整为“已提交系统安装会话，等待系统弹出安装确认界面”，不再提前宣称系统已经显示安装页面。
- 移除本次更新流程不再需要的 FileProvider 注册和缓存 URI 配置。版本、下载和安装回归测试同步覆盖新的安装会话及回调注册方式。

## 其他变更

- APP 版本从 2.0.25 更新至 2.0.26，以便已安装的 2.0.23/2.0.25 检测升级。
- 不修改路由器端 UCI 配置、网络管理功能、阿里云 APK 镜像和签名发布流程。
- 此修复需要先安装 v2.0.26 才能生效；旧版本中的安装器仍可能报错，可先使用系统浏览器下载新 APK 并从系统文件管理器打开安装。
