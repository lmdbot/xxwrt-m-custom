# XX-WRT Material v2.0.44

## 新功能

- 移除原有左侧导航抽屉及边缘滑动呼出手势，将“更多”作为底栏第六个固定入口，保留首页、统计、终端、网络、应用原有顺序。
- 新建“更多”主页面，展示随 APK 内置的应用图标，以及路由器、设置、关于三个一级入口。
- “设置”二级页面收纳显示、隐私、刷新、实验室、语言五项功能，继续复用原有设置内容和本地偏好。
- “路由器”入口增加设备信息、连接设备、接口状态、系统信息快捷入口，未连接时禁用依赖路由器会话的操作。
- “关于”入口继续使用 v2.0.43 已修复开发者头像的原有关于页面。

## 优化

- 标准底栏与液态底栏均扩展到六个入口，兼顾 360px 手机屏幕和系统减少动态效果。
- 设备列表尚未登录时也可使用“更多”访问设置、语言和关于，避免删除侧栏后丢失入口。
- Android 返回顺序为：设置详情 → 设置目录 → 更多首页 → 上一底栏页面；切换其他底栏入口时收起二级菜单。
- 更新中文、英文、繁体中文菜单翻译及 UI 回归测试。

## 发布

- APP 版本提升到 v2.0.44，Android 构建号由现有自动化工作流生成。
- 不修改 Android 包名、签名方式、路由器 RPC 业务逻辑和更新渠道。
