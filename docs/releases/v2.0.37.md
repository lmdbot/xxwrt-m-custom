# XX-WRT Material v2.0.37

## 修复

- 修复 QWRT 固件被误判为原版 OpenWrt 的问题：综合 RPC 发行版标识、描述与可读取的系统发行信息，优先识别 QWRT、KWRT、KWRP、ImmortalWrt、iStoreOS、FriendlyWrt、LEDE 等衍生发行版。
- 改善长期趋势的 CPU 采样兼容性：支持不同 LuCI CPU 使用率字段及百分比格式；当 LuCI CPU 读取不可用时，尝试依据 `/proc/stat` 的两次真实累计计数计算 CPU 占用率。
- 修复长期趋势仅有单条有效采样时难以看出图形的问题，增加有效数据点标记。

## 优化

- 长期趋势新增「立即采样」按钮，可尝试从当前连接的路由器采集，并更新本机历史数据。
- 显示选定时间范围内的有效指标样本数、原始样本数和最近保存时间；完善 CPU 采样预热和无权限时的提示。
- 在 5 分钟去重窗口内允许后续完整采样补全缺失的 CPU 指标，保留原有监控历史数据格式。
- 系统能力识别页区分具体发行版与 OpenWrt 兼容体系。
- 增加系统发行版识别、CPU 百分比解析、`/proc/stat` 回退采样和历史样本补全的自动化测试。

## 注意

- 监控历史仍保存在本机 APP 中，最长 30 天；APP 关闭或离线期间不会自动产生采样数据。
- `/proc/stat` 回退采样需要路由器当前账号拥有相应 RPC 文件读取权限；首次采样为计数预热，至少两次有效读取才可计算 CPU 使用率。
- 固件品牌识别基于路由器实际暴露的发行信息；系统未提供足够证据时会显示「OpenWrt 兼容 / 待确认」。
