# XX-WRT Material v2.0.18

## 修复

- 修复英文模式下部分悬浮通知、操作成功/失败反馈仍显示中文的问题，补充常见插件操作提示及路由器 RPC 错误提示的英文译文。
- 修复 WeChat Push 推送渠道下拉选项、OpenClash 代理模式选项，以及部分插件动态选择项在英语界面中仍为中文的问题。
- 修复 Lucky 重新读取规则时原生“丢弃未保存内容”确认框未随语言切换的问题。
- 补齐 Carbon、ZeroTier、SSR Plus+、OpenAppFilter、Vlmcsd 等管理页面的确认与错误提示翻译。

## 优化

- 将弹窗、下拉选项、悬浮通知、错误提示等动态内容统一纳入英文翻译覆盖范围，不修改设备名称、IP、MAC、规则文件及用户输入。
- 为异步追加到页面的 Vuetify 浮层增加 Playwright 回归测试，验证英文显示与切回繁体中文后的可逆转换。
- 扩充语言转换单元测试，检查动态通知拼接、菜单选项及插件确认文案。

## 其他变更

- 上游路由器或第三方插件原样返回的未知错误内容仍可能保留源语言；应用自身常见操作提示已经补充英文。
