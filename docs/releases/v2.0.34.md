# XX-WRT Material v2.0.34

## 新功能

- **DDNS 管理**：区分标准 OpenWrt `ddns-scripts` 和独立 `DDNS-Go`。查看服务运行状态、已有 DDNS 配置、IPv4/IPv6 选择及指定服务日志，并提供 DDNS-Go 服务的授权启动/停止/重启；对已有 `ddns-scripts` 配置进行安全修改，敏感的用户名、密码、Token 和订阅 URL 不纳入编辑或操作审计。
- **OpenClash 深度管理**：在原 OpenClash 页面增加可识别的 `config_subscribe` 订阅配置列表、启停、现有 YAML 配置选择、当前主配置路径及运行日志查看；未证实可用的 Controller 动态代理组接口、强制订阅更新与内核更新不展示虚假按钮。
- **防火墙增强**：在原防火墙页面增加 IPv4、IPv6、双栈的规则创建，可选择现有来源区域、来源网段、协议、目标端口与 ACCEPT/REJECT/DROP，新增规则先预览后采用 UCI 90 秒回滚确认。保留原有区域策略、端口转发和规则启停功能。
- **系统定时任务**：读取 `/etc/crontabs/root`，支持对已有普通五段式 Cron 任务进行启停、周期调整及删除，并支持创建固定命令的 DDNS/OpenClash 服务维护预设。不提供任意 Shell 执行框。写入前核对当前文件，写入后校验回读，失败时尝试恢复原内容。
- **长期监控与趋势**：增加 CPU、内存、连接占用率和系统 1 分钟负载的最多 30 天本地历史样本。连接期间按 5 分钟上限采样，显示 24 小时、7 天、30 天曲线和有效样本数；离线时间段不推断、不补造数据。
- **拓扑与链路可视化**：结合 LuCI 主机提示、无线关联终端和可选 `lldpcli` JSON 邻居形成链路图。区分由 LLDP/实时无线关联确认的邻接与历史地址提示推断的关联；不凭 DHCP 租约认定设备在线或物理接线端口。
- **安全事件分析**：对当前可读取的系统/内核日志识别认证失败、明确记录的防火墙阻断、端口扫描/洪泛和 DNS Rebind 等模式，并展示类别数量、原始证据及来源。仅表示日志匹配，不推断攻击者归属地或真正的入侵定性。
- **固件能力自识别**：根据 `system.board`、`rc.list`、UCI 与标准 RPC 返回值识别 QWRT/OpenWrt、已授权能力与插件可用性；不可读取时标识“无法确认”，不把 ACL 拒绝当成未安装。
- **统一配置变更保护与审计**：对新增加的 DDNS、OpenClash、扩展防火墙 UCI 修改统一执行格式校验、外部待提交变更检查、基线校验、字段级预览和 `uci.apply(rollback=true,timeout=90)` 后确认/回滚；对经过 `RouterClient` 的 UCI/服务/文件修改 RPC 按设备本地保存脱敏审计事件，记录时间、操作对象和成功/失败/未知状态，不保存请求参数中的凭据。
- **日志与操作记录中心**：原有系统/内核日志页面增加 APP 本地审计日志入口，同时新增独立操作记录查询页面，可搜索和复制脱敏记录。

## 优化

- 保持现有五个底部导航不变。新增七个应用入口归入「网络与安全」「系统工具」分类；OpenClash 与防火墙的深度功能仍放在各自原有页面。
- 原有 OpenClash、防火墙等部分 UCI 写入入口补充未处理 UCI 变更检查，以减少覆盖 LuCI 尚未保存的编辑。
- 统一审计将 RPC 明确拒绝与网络中断导致的“执行结果未知”分开记录；断线情况下不自动重复敏感操作。
- 优化回滚确认倒计时、返回导航拦截和过期事务锁释放。

## 修复

- 更新 Android Playwright 启动器验证：适配新增功能后 29 项入口，并逐一检查 P1/P2 与能力页面可见性。
- 增加能力、配置保护、DDNS/OpenClash、IPv6 防火墙规则、Cron 文件防护、历史采样、拓扑可信度与安全日志匹配的 Node.js 回归测试。

## 注意

- **历史趋势只在 APP 运行并连接时收集**，本地 30 天是保留上限，并非保证 24 小时全时覆盖；需要全天采集请部署服务器或路由器侧监控采集器。
- **DDNS-Go** 当前支持识别服务状态及通过授权的 rc.init 启停/重启；其独立配置仍不能通过 ddns-scripts UCI 接口安全修改。OpenClash 代理组实时切换及无厂商 RPC 授权的操作同样不伪装为已支持。
- 使用 UCI 保护的本版**新增配置页面**具备 90 秒回滚确认。历史功能中的部分保存逻辑仍通过既有 UCI 提交及服务重载流程，新增的前置冲突检查和审计不等于这些历史路径已经全部迁移到回滚事务；网络接口配置页此前已单独支持自动回滚。
- root Cron 文件可能包含敏感命令参数，APP 列表只展示命令可执行文件名称；从 GUI 修改任务前仍应预先备份原始 Cron 文件。
- 可用功能依赖实际 OpenWrt/QWRT 固件、插件版本与 rpcd ACL。GitHub Actions 的模拟测试不能代替在真实路由器上的 IPv6、防火墙、Cron 和断线回滚测试。
- v2.0.32 的 HQoS 和多 QoS 后端代码在本次更新中未改动。
