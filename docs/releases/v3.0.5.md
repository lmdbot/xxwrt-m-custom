# XX-WRT v3.0.5

## 概览

- 实时资源卡片调整为两行六项，每行三张：CPU 占用、内存占用、存储、温度、终端、联网监测。
- 温度继续使用现有路由器实时温度接口；未能读取时显示“--”，不虚构数据。
- 联网监测复用 Internet Detector 检测结果，以“正常数/总数”展示；全部正常为绿色、部分正常为橙色、全部异常为红色。插件不可读时显示“--/--”，未配置监测项时“0/0”保持中性。
- 调整小屏幕字号与卡片间距，始终保持三列排布。

## 关于

- 优化“版本日志”入口：图标、标题、辅助说明与右箭头组成统一的可点击行，改善点击区域与暗色主题观感。
- 保留更新日志加载状态与既有更新下载安装操作。
