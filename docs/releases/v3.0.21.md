# XX-WRT v3.0.21

## 修复

- 修复**设备页手动刷新无效**：明确点击顶部刷新时绕过 45 秒的启动预加载缓存，重新请求 DHCPv4/v6 租约、微信推送设备与备注、无线关联以及 OpenAppFilter 用户，并将最新数据更新至当前设备列表。
- 修复单路由器启动后从概览切换到设备页时，刷新被早期预加载请求吞掉的问题：在预加载尚未结束时，手动刷新会等待该请求完成，再执行一次强制读取；普通切页仍使用缓存，避免重复请求。
- 修复**路由器管理列表刷新被后台检测占用时直接丢失**的问题：手动检测可排队，在上一轮结束后再次逐台检查；列表显示最近检测时间，便于确认操作已执行。
- 修复删除所有路由器后再次启动，旧版 `xxwrt_material_router_url` 地址（如 `istoreos.12130812.xyz`）被恢复成一台虚假设备的问题。旧地址仅在新版设备列表**不存在**时迁移一次，明确保存的 `[]` 永不重新导入。
- 强制读取终端的主要 RPC 失败时显示错误，不再仅更新刷新时间并保留未说明的旧数据。

## 兼容性

- 保留 v3.0.19 启动预加载的 45 秒去重策略，仅用户明确手动刷新时跳过。
- 保留原路由器账号、Keystore 加密密码、设备配置和多入口配对；无需清除 App 数据。
- 增加 Playwright UI 回归及旧地址迁移单元测试。
