# XX-WRT M Custom v1.0.6 — 稳定基础版

> 2026-11-14 基础功能版本（Baseline）。此版本供稳定使用及作为后续 UI 美化的回退基准；新一代 Material UI 开发在独立分支进行，不覆盖本 Release。
>
> 非官方修改版。基于用户提供的 XX-WRT M v1.0.6 Android APK；本仓库保存的是提取的**已编译 UniApp 资源**及补丁脚本，并非原作者的 Vue/Android 原始工程。

## 一、应用功能与体验改进

- **启动去广告**：移除原 APK 启动后首页广告弹窗触发逻辑。
- **移除底部推广信息**：隐藏首页底部邮箱文字及外部链接。
- **外观模式**：新增“跟随 Android 系统 / 浅色 / 深色”，根据系统深浅色模式切换，应用回前台时再次检查。
- **保留既有管理功能**：设备连接、路由器首页、统计、终端、网络、应用等原有模块仍由原 APK 提供。

## 二、QWRT 硬件温度

- 登录后的路由器首页增加硬件温度显示。
- 修复设备列表中的温度解析，兼容毫摄氏度格式（例如 39000 → 39℃）。
- 优先兼容 luci.getTempInfo，必要时回退到 thermal/hwmon；部分 QWRT 固件需要部署只读 RPC 温度接口（仓库 router 目录提供供审查的安装脚本）。
- 读取不到时显示不可用；传感器、权限、固件版本不同可能造成数据差异。

## 三、Internet Detector 联网监测

- 基于 OpenWrt Internet Detector RPC 读取当前监测实例的结果，避免 APP 重复探测。
- 保留**全部监测项**，不再只显示前三项、以 +N 概括其余项。
- 正常（绿色）、断开（红色）、检测中（黄色）及读取失败、未配置实例等状态处理。
- 汇总“正常实例数 / 总实例数”，随实时数据更新。
- **两列紧凑胶囊布局**：圆角、边框、分状态配色、自动换行，适配深色和浅色主题。
- **位置与排版**：放在“本地时间、运行时间”之后，CPU、内存等资源监控卡片之前。
- **名称规范化**：netease_music → **网易云**；chatgpt → **ChatGPT**；github → **GitHub**；youtube → **YouTube**；其余常见目标为 Telegram、Baidu、Google、Internet。
- **字号统一**：联网监测标题普通字重；标题、汇总、胶囊名称与状态按“运行时间”行的 26rpx 字号统一。
- 修复已编译 UniApp 的 app-service.js、app-view.js 节点和样式配对，解决“undefined”、拥挤、文字无样式、胶囊渲染失效等问题。

## 四、自动构建、固定签名与发布

- 从 src/www 提取编译的前端资源，通过 scripts/repackage.py 叠加到 vendor/base.apk，保留原有 Android/UniApp 运行时。
- GitHub Actions 完成 JavaScript 语法检查、APK 重打包、Zipalign、固定 P12 签名及 apksigner 验证。
- 固定签名密钥通过 XXWRT_KEYSTORE_BASE64 与 XXWRT_KEYSTORE_PASSWORD 两项 GitHub Actions Secrets 注入，**不提交 P12/私钥**。
- 签名证书 SHA-256：**E7:B3:D7:9A:5C:7D:C2:8D:FF:DE:6B:0B:D9:22:63:DA:B9:49:18:DD:C3:E7:EC:60:5B:79:CE:B2:E4:5A:B9:81**。
- 修复 Android SDK 初始化请求已移除的 tools 包、zipalign -h 不兼容等 CI 环境问题。
- 自动识别真实 APK versionName；新版本创建 Release，相同版本更新既有 Release、覆盖 APK 附件；发布构建串行执行。
- 当前 APK 版本仍为 **1.0.6**。同包名、同修改版证书通常可覆盖安装；官方原版如果签名不同则不能直接覆盖升级。

## 五、范围与限制

- 此为**稳定基础版**；后续 Material / 液态底栏实验独立在 feature/material-ui 分支开发。
- 这不是原生 Android 源码项目，也不是可直接导入 HBuilderX 的原始 Vue 工程，不能未经验证就直接加入 npm 组件并认为已集成到 APK。
- CI 已验证资源覆盖、语法、打包、签名与上传；Android 真机上的界面及路由器兼容性以实际安装测试为准。
- 请确认拥有对原版应用进行修改及再分发的合法授权。此版本是非官方改版。
