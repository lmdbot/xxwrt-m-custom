# XX-WRT Material v3.0.2

## 新功能

- 根据 `doc/`「方案 A」实现五底栏页面结构的进一步收敛：概览、设备、网络、工具、我的。
- 概览采用四项核心指标（CPU、内存、存储、终端）与流量预览，系统和硬件详情按需展开；不生成虚拟速率。
- 终端提供按数据来源的合并列表与在线 / 离线 / 待确认筛选；DHCP 租约不能单独证明在线。
- 网络页面从首页入口直接进入网络接口、物理设备、无线设备，移除二次选择层。
- 我的按「路由器 / 应用设置 / 支持与更新」分组，并在顶部提供当前路由器切换控件。

## 优化

- 首页快捷入口进入「网络接口」后，返回上一级可以回到原概览页面而非跳到网络分类首页。
- 浅色/深色主题与 `doc/04-design-system.md` 对齐，优化卡片间距、网格、圆角、状态和 360dp 触控布局。
- 28 项现有管理工具及每台路由器保存的收藏保留；网络配置、UCI 回滚和敏感配置确认流程不变。
- 修正磁盘用量查询故障提示，明确底层采用 `luci.getMountPoints` 接口而非 df。

## 其他变更

- 同步升级导航与 UI 自动化断言，避免把已移除的重复网络分类器作为验收条件。
- UI/UX 截图和原型属于设计示例；正式 APP 仍以路由器返回的实际信息为准。
- 涉及不同固件版本、RPC 权限与插件的实际兼容性，需要 Android 真机继续验证。
