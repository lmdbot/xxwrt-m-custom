# XX-WRT管理器 v2.0.16

## 新功能

- **开源许可证：** 设置 → 关于新增开源许可证入口，可在 APP 内离线阅读 MIT、Apache-2.0 全文，并查看主要第三方运行依赖及其授权来源。

## 优化

- **正式开源授权：** 添加标准 MIT License、第三方开源致谢与声明，保留上游组件各自许可证。
- **授权边界：** 单独登记旧版 UniApp 资源、`vendor/base.apk`、Carbon 品牌识别数据及 Simple Icons/IEEE 数据的许可范围，避免擅自重新授权。
- **自动化回归：** 增加 LICENSE 与 APP 内文一致性校验、第三方直接依赖覆盖测试和“关于”页开源许可证入口测试。

## 其他变更

- 本版本不改变现有 QWRT/OpenWrt 管理 RPC 或用户配置；旧版编译资源暂保留以维持历史手动构建兼容。
