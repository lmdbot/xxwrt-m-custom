# XX-WRT Material v2.0.16

## 新功能

- 侧边栏设置新增独立“语言”分类，可在简体中文、繁體中文和 English 之间即时切换。
- 语言设置保存在 Android WebView 本地存储中，重新打开 APP 后仍保留。
- 引入 OpenCC.js 离线简繁转换，并为设备列表、路由器监控、网络管理、应用插件及系统设置增加英文界面译文。

## 优化

- 语言切换适用于动态加载的 Vuetify 页面、弹窗、提示与无障碍标签，不影响设备连接数据或用户输入内容。
- 增加中英繁转换单元测试与 Playwright 侧边栏切换、重启后持久化回归测试。

## 其他变更

- 更新开源依赖致谢，补充 OpenCC.js 的许可信息。
- 部分由路由器第三方插件动态生成的详细消息可能继续显示源语言。
