# XX-WRT v3.0.36

## 终端页面展示优化

- 状态未确认的设备不再显示“待确认”状态徽标，灰色状态圆点仍保留，在线和离线状态照常显示。
- 终端卡片隐藏“微信推送”“小米记录”数据来源标签，保留 DHCP、LAN、随机 MAC 等有用的设备信息。
- 小米历史无线接入记录在频段未知时改为“曾接入 · 无线”，不再显示“频段未知”及括号；已知的 2.4G/5G 频段继续展示。
- 终端详情同步隐藏未知状态徽标，避免与列表展示不一致。

## 兼容性

- 仅调整界面显示和无线接入类型文字，不调整 QWRT、微信推送、小米的数据抓取、合并、设备准入或在线状态判断规则。
- 既有无线接入类型测试同步更新预期标签。
