# XX-WRT v3.0.30

## 修复：小米查询 RPC -32000

- 修复设备页小米路由器验证报 `RPC 调用失败（代码 -32000）` 无法判断原因的问题。根据 OpenWrt uhttpd JSON-RPC 实现，-32000 表示 **Object not found（ubus 对象不存在）**，并非小米密码错误。
- 小米 rpcd 插件在收到 `list` 注册请求时先直接输出签名，不再提前加载 `jshn.sh`；即使运行时 JSON 依赖暂时失效，也不应阻碍对象签名发现。
- 安装脚本不再仅打印“Installed”就视为成功：先检查插件可执行与 `list` 签名，重启 rpcd 后最多六次检查 `ubus -v list luci.xxwrt-xiaomi` 中是否存在 `Fetch`，然后使用不可路由的回环地址进行本地拒绝校验，确认 `Fetch` 可以被调用，只有全部成功才打印 SUCCESS。
- QWRT 端验证失败时输出具体失败步骤与 rpcd 日志提示；Android 显示针对 -32000 的可操作解释，避免误判为小米密码不正确。
- 保持 `luci.xxwrt-xiaomi.Fetch` 最小 ACL 和内网目标白名单，不开放通用 `file.exec`；微信推送/邻居表继续独立判断终端在线。

## QWRT 端升级

**本次需要重新下载安装 QWRT 辅助脚本，单升级 APK 不会重新注册路由器上的 rpcd 插件。**

将仓库 `router/` 目录下两个最新文件复制到 QWRT 的 `/tmp/`，以 root 运行：

```sh
sh /tmp/XX-WRT-QWRT-xiaomi-install.sh
```

安装结果必须出现 `SUCCESS: QWRT has registered and executed luci.xxwrt-xiaomi.Fetch.`。
如果出现 `Failed to register`，说明 QWRT 的 rpcd 没有发现插件，请检查输出的日志与当前固件支持情况，不能将安装视为成功。

安装成功后，回到 Android App **重新连接 QWRT**，再进入“设备 → 小米路由器 → 配置”验证现有 IP/密码。
