# XX-WRT v3.0.29

## 修复：小米设备查询提示 RPC 权限错误 6

- **错误原因**：旧方案尝试通过 QWRT 的通用 `file.exec` 执行 `/usr/bin/curl`，而 OpenWrt rpcd 对可执行程序实施单独的文件权限 ACL 校验；未授权时会返回状态码 6。
- 改为调用专用的 `luci.xxwrt-xiaomi.Request` RPC 方法，移除对通用 `file.exec` 的依赖。
- QWRT 端只放行私有 IPv4 地址及小米登录、设备列表 API，不允许任意 URL、命令或重定向；限制连接超时和输出大小。
- 新增一次性安装脚本 `router/XX-WRT-QWRT-xiaomi-install.sh`，安装 QWRT 的专用 rpcd 可执行插件与**仅授权该 RPC 方法**的 ACL 配置；保留升级配置清单。
- App 检测到 QWRT 权限不足或插件缺失时，显示明确的安装提示，并可一键复制 QWRT 端安装命令。
- 小米密码仍加密保存在 Android；App 本地计算摘要，QWRT 仅负责向小米设备发请求。终端在线状态继续以 WeChatPush / QWRT 为准。

## 首次启用

1. 在 QWRT 上以 root 执行：
   ```sh
   curl -fsSL https://raw.githubusercontent.com/lmdbot/xxwrt-m-custom/main/router/XX-WRT-QWRT-xiaomi-install.sh -o /tmp/XX-WRT-QWRT-xiaomi-install.sh && sh /tmp/XX-WRT-QWRT-xiaomi-install.sh
   ```
2. 重新连接 QWRT，然后在终端页面重新点击小米“验证并保存”。

要求 QWRT 已有 `curl`、`jsonfilter`、`rpcd`，且 QWRT 可访问小米路由器的 LAN IP。此步骤需要 QWRT 本地管理员执行，App 不会尝试绕过权限控制自安装。

## 验证

- 增加接口权限拒绝、路径/私有 IP 白名单、登录摘要、RPC 错误映射及 shell 语法检查。
- 未直接连接用户的 QWRT / 小米硬件进行真机验证，实际固件与 ACL 权限仍以设备结果为准。
