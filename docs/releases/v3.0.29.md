# XX-WRT v3.0.29

## 修复

- 修复小米路由器配置时 QWRT 返回 RPC 权限错误（代码 6），无法访问小米管理接口。
- 不再通过通用 file.exec 执行 curl，而改用最小授权的 luci.xxwrt-xiaomi.Fetch 专用 RPC；无需放开任意命令权限。
- 专用 QWRT 扩展只允许 RFC1918 局域网 IPv4 和白名单小米 API（init_info、login、设备列表），禁用代理和重定向，限制请求时间及响应体大小。
- 小米管理密码仍保存在 Android 安全存储中；App 计算登录摘要，通过已认证的 QWRT 会话发送固定查询请求。
- 缺少扩展、权限错误时显示明确安装提示；小米数据获取失败不影响 WeChatPush / QWRT 的终端在线状态。

## QWRT 端首次部署（必须管理员执行一次）

从仓库的 router 目录下载以下两个文件到 **QWRT 的 /tmp**：

1. luci.xxwrt-xiaomi
2. XX-WRT-QWRT-xiaomi-install.sh

登录 QWRT SSH 终端，以 root 执行：

```sh
sh /tmp/XX-WRT-QWRT-xiaomi-install.sh
```

安装会生成只允许调用 luci.xxwrt-xiaomi.Fetch 的 RPC ACL，并重启 rpcd。之后请在 Android App 中重新连接 QWRT，再在“设备 → 小米路由器 → 配置”中验证。

**不可**直接给 file.exec 或 /bin/sh 配置通用权限；当前已受限制的 QWRT 账号无法从 App 自动绕过权限完成首次安装。
