# XX-WRT v3.0.12

## 优化

- 「我的 → 关于」版本更新提示卡片将原先的纯转圈按钮改成**胶囊内下载进度显示**，按 Android APK 下载器上报的真实字节量和百分比，从左向右填充按钮背景，并实时显示百分比。
- 下载期间卡片左侧显示「正在下载 vX.Y.Z」与「已下载大小 / 总大小」，不新增独立的进度条，也不需要滚动到页面下方查看下载进度。
- 下载完成后明确区分「校验及准备安装」与「安装包已下载完成」；保留 Android 系统安装会话的原有安全校验和安装交互，允许直接在顶部重新打开安装。
- 下载失败或取消后在原位置显示「重试下载 / 重新下载」；总大小未知时显示下载中与已接收字节，不伪造 0%。
- 优化深浅模式中的按钮文字对比度与窄屏布局，并尊重 Android 的减少动态效果偏好。
- 去掉「版本与更新」区域原有的重复独立下载进度条及重复下载按钮，保留必要的取消下载入口。
