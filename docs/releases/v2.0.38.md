# XX-WRT Material v2.0.38

## 新功能

- 重新设计设备拓扑页，新增「概览 / 拓扑图 / 设备列表」三视图。
- 新增链路证据概览、设备类型分组示意、数据来源状态以及按名称、IP、MAC、类型、数据来源筛选设备。
- 未知设备默认汇总为单个分组；点击分组可进入设备列表，点击设备可展开来源和关联证据。

## 优化

- 用轻量化分组示意替换手机端难以阅读的几十条放射状连线；明确告知分组虚线并非实际物理链路。
- 根据设备名称特征显示友好名称与类型图标，未知设备不强行识别。
- 增加 DHCP 租约和 Host 提示的独立读取来源，并按 MAC 与无线关联数据归并，去除重复节点。
- 增加「仅查看当前观测证据」筛选，严格区分 Wi-Fi 关联、LLDP 邻接与仅有历史提示的设备。
- 修订链路证据覆盖和数据来源说明，防止将 DHCP 租约或地址提示误报为在线状态。
- 补充拓扑分类、证据分组、筛选、汇总与去重回归测试。

## 注意

- 历史 Host 提示、DHCP 租约和设备名称不能证明设备当前在线或直连路由器。
- 概览中的示意连接线不是经过发现的真实交换机端口或物理链路；LLDP 与 Wi-Fi 信息也只覆盖路由器可观测范围。
- 设备友好名称来自 hostname 特征解析，可能需要用户后续人工核实；未提供的数据（端口/链路/在线状态）不会推测。
