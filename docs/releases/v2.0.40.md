# XX-WRT Material v2.0.40

## 新功能

- 新增“设置 → 显示 → 界面动效”开关，默认开启，设置仅保存在本机 APP。用户可以随时关闭页面进入、卡片反馈、弹窗/菜单、折叠面板、加载动效、实时曲线和滚动动效。
- 五个底栏首页页签（首页、统计、终端、网络、应用）支持重复点击当前页签，平滑滚动返回页面顶部；关闭动效或系统要求减少动态效果时立即返回顶部。

## 优化

- 对页面进入采用短时（约 200ms）、低位移的轻量过渡；列表与导航提供简洁按压反馈，不对持续刷新的数据重复执行页面级动画。
- 遵循 Android / Web `prefers-reduced-motion`，系统开启减少动态效果后始终覆盖 APP 内开关；实时 ECharts 更新改为无动画。
- 液态玻璃导航在动效关闭时改用静态玻璃底栏，避免渲染动态装饰层，同时保留导航功能与原有视觉形态。
- 统一控制 Vuetify 弹窗、抽屉、菜单、Snackbars、展开收起、骨架屏、进度反馈及 CSS 交互动效。所有开关状态均覆盖弹出到应用根节点以外的浮层。
- 展开全部应用的自动滚动尊重动效设置；导航离开页面及返回子页面继续使用即时滚动恢复，避免滚动位置错乱。
- 避免标准底栏点击事件重复处理：使用单一点击入口。位于应用子页面时，第一次点“应用”只返回功能列表并恢复之前的位置，再点一次才滚回顶部。
- 补充动效偏好、系统减少动态效果、五页签回顶及手机端交互回归测试，新增动效覆盖清单。

## 注意

- 本开关仅控制视觉动效，不影响后台请求、加载状态提示、页面操作或路由器配置。
- 长期趋势的真实样本采集间隔和数据仍保持不变；关闭动画不删除或改变监控数据。
- 第三方原生 Android 系统动画（例如系统文件选择器、安装器、系统设置页面）遵循手机系统，不由 APP 的 WebView 页面开关直接控制。
