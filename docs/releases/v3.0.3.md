# XX-WRT Material v3.0.3

## 新功能

- 新增设计方案 A 逐页视觉验收工具：21 个代表页面、3 种手机宽度、深浅主题；可生成原型图、实际 Vue 截图、叠加图、差异图和 JSON/HTML 审查报告。
- 增加 Android 实机取证辅助脚本，通过 adb 只读截屏并记录系统版本、屏幕密度和逐页验收清单；执行依赖具备调试权限的真实手机。

## 优化

- GitHub Actions CI 的 Playwright 浏览器回归改为三个并行 worker，并保留原功能断言和失败重试；添加每项测试的耗时统计及慢测试排行。
- 缓存 npm 下载、Chromium 和 Gradle 依赖，减少同一依赖反复下载及 APK 构建准备开销。
- 将长时间综合 UI 测试中固定等待采样替换为真实采样数条件轮询，降低不必要的空等与因 CI 资源竞争导致的误超时。
- 按设计系统将 360dp 侧边距调整为 16dp，393dp 及以上采用 18dp，并增设宽度、主题和底栏触控区域断言。

## 其他变更

- 完善 `doc/07-visual-acceptance.md` 的逐屏视觉清单、像素差异报告使用方法及真机验收前置条件。
- 当前视觉比对结果仅为**设计评审诊断**：参考 HTML 使用演示数据，与真实 APP 的系统栏、数据和组件行为并非逐像素相同；没有完成 100% 像素一致性签收，也没有完成物理 Android 设备验收。
- 所有网络操作、权限、UCI 写入与回滚保护保留原有逻辑。
