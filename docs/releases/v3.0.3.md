# XX-WRT Material v3.0.3

## 新功能

- 终端设备列表补充显示/隐藏 IP 地址、按设备名称或 IP 排序，保留原有数据来源和在线状态筛选。
- 设备筛选按「全部 / 在线 / 离线或未知」展示，来源筛选可折叠；在线状态继续区分可验证状态与待确认。
- 终端详情页返回箭头改为可操作按钮，并继续保护正在保存的配置。

## 优化

- 依据 `doc/visuals/primary-pages.svg` 和方案 A 的页面规范，修正概览卡片、实时资源、网络概览、工具分类、个人设置页面的颜色、间距和层级。
- 修正标准与轻玻璃两种底栏的五项等宽排布、选中态以及窄屏适配。
- 恢复概览及工具快捷入口的设计配色，统一深色模式下的状态文本、边框和面板表现。
- Android Actions 增加 npm、Playwright Chromium 和 Gradle 依赖缓存，不改变现有回归断言或构建签名机制。

## 修复

- 避免终端详情页的返回图标不可点击，以及浮层缺少 Design A 样式范围。
- 避免未取得可靠在线证据时使用误导性的网络状态展示。
- 从独立的 v3.0.2 升级为 v3.0.3，避免复用已发布 APK 的版本号。

## 其他变更

- UI 视觉审计不添加新测试用例；当前改动基于设计稿和现有组件实现。
- 当前版本尚需在实际 Android 设备上进一步核对像素、状态栏安全区和交互表现；不声称已达到百分之百视觉一致。
- 保持现有路由器 RPC、UCI 配置写入、权限限制和危险操作确认流程。
