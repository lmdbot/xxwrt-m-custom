# XX-WRT v3.0.26

## 修复

- 修复 WeChatPush 已安装且设备监控文件可读，却因为 `rc.list` / `service.list` 报告进程“未运行”，导致设备页在线状态全部显示“待确认”的误判。
- 设备页仍从当前路由器重新读取 `/tmp/wechatpush/devices.json`。以本轮成功读取、格式有效的 WeChatPush 设备记录为依据，不再仅因服务状态接口的假阴性而舍弃数据。
- 当设备文件读取失败、超过大小限制或 JSON 不合法时，仍明确显示数据不可用；不使用 App 端历史终端快照冒充实时数据。

## 优化

- “工具 → 我的快捷”长标签按语义进行两行排版：例如 ShadowSocksR / Plus+、Internet / Detector、Carbon / 主题设置、配置备份 / 恢复。
- 短标题保持单行；统一图标下文字区域的高度和对齐，减少窄屏随机断行。

## 验证

- 更新 WeChatPush 设备解析及终端状态测试，覆盖有效设备文件与服务状态假阴性并存、文件缺失、JSON 格式错误等场景。
- 通过前端构建与逻辑回归测试；真实路由器的 WeChatPush 更新周期和 RPC 文件读取权限仍需在设备上确认。

> 说明：`devices.json` 是 WeChatPush 在路由器端维护的监控快照。App 每次重新读取路由器文件，但不会改变 WeChatPush 自身的检测频率。
