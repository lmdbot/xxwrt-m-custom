# XX-WRT管理器 v2.0.10

## 优化

- **微信推送在线时间：** 正确识别 `devices.json` 中记录的设备上线 Unix 时间戳，以当前时间减去上线时刻，再自适应显示“45秒”“2分钟5秒”“1小时1分钟”“1天1小时”等时长；兼容旧版数值秒数和已经格式化的时间。
- **在线设备排版：** IP 地址与 MAC 地址合并为同一行；窄屏时仍保持单行，可横向查看完整内容。

## 修复

- 增加微信推送在线时长换算及列表排版自动化测试。
- 补齐缺失的 v2.0.8、v2.0.9 Release 说明，避免此前 APK 已构建成功但因版本说明缺失导致发布中断。
