# XX-WRT v3.0.28

## 修复

- 将小米路由器登录和设备列表查询由“Android 手机 → 小米路由器”改为“Android App → QWRT ubus → QWRT 发起本地 HTTP 请求 → 小米路由器”。
- 通过 QWRT 认证后的 file.exec 运行固定路径的 curl 命令。手机无需直接访问小米管理地址，只需连接已登录的 QWRT。
- 小米设备自动刷新、手动刷新、首次验证均使用同一条 QWRT 转发通道，不会再直接从手机请求小米路由器。
- 小米管理密码仍保存在 Android 安全存储中；App 在本地计算登录摘要，只向 QWRT 转交认证摘要和固定的小米接口请求。小米 stok 会话按当前 QWRT 登录实例隔离。
- 限制目标为私有 IPv4 小米管理地址及白名单 API 路径，禁止代理与重定向，并限制请求时间、响应大小，避免任意地址转发。
- 如果 QWRT 缺少 curl、file.exec 权限不足、与小米不通，界面会显示可诊断的错误，不再以小米信息影响设备在线状态。

## 环境要求

- **QWRT 能在局域网访问小米路由器**，手机无需与小米路由器互通。
- QWRT 安装 /usr/bin/curl，已登录账号具有 file.exec RPC 权限。
- 手机与 QWRT 的管理连接应保持安全，避免明文传递登录证明（建议 HTTPS）。
- 小米固件仍需提供兼容的 MiWiFi 登录和设备列表 API；具体固件兼容性待实际设备确认。

## 验证

- 新增 QWRT 代理请求测试，覆盖白名单路径、非公开地址校验、POST、代理和超时约束以及 RPC 错误。
- 保留既有小米类型映射和独立在线状态规则，不改变 WeChatPush 监控来源。
