# XX-WRT v3.0.32

## 小米 BE5000（RD18）登录流程兼容修复

- 已确认 QWRT 经 `luci.xxwrt-xiaomi.Fetch` 能成功请求用户的 BE5000（RD18）固件 1.0.87 `/cgi-bin/luci/api/xqsystem/init_info`，响应 `code=0` 且 `newEncryptMode=1`。
- 此响应**不包含登录所需的 key**。此前 App 错误地要求 `init_info.key`，导致 RPC 通道打通后仍不能登录。
- 改为由 QWRT 安全转发只读 `GET /cgi-bin/luci/web`，从公开管理登录页 HTML 提取 `key` 和真实 `deviceId`（MAC 地址），同时从 `init_info` 决定 SHA-256 / SHA-1。
- nonce 从模拟固定 MAC 改为 `0_设备实际MAC_时间戳_随机数`，使用 `H(nonce + H(管理密码 + key))` 得到登录摘要，向小米提交表单。
- 保持明文管理密码仅存于 Android 安全存储，不传给 QWRT；只增加白名单 GET 登录页请求，不开放任意 HTTP 或 `file.exec`。
- 增加 HTML 校验、登录 key/MAC 校验以及 RPC 通道和非法请求的回归测试。
- 终端在线状态仍由 WeChatPush/QWRT 决定，小米只补充 2.4G/5G/LAN 元数据。

## 升级步骤

1. 安装 v3.0.32 Android APK。
2. 在 QWRT 上下载最新 `router/luci.xxwrt-xiaomi` 和 `router/XX-WRT-QWRT-xiaomi-install.sh` 到 `/tmp`，以 root 运行 `sh /tmp/XX-WRT-QWRT-xiaomi-install.sh`。**仅升级 APK 不会自动更新 QWRT 插件**。
3. 重新登录 App 内 QWRT，再验证小米路由器。若登录页 HTML 格式不同，App 会给出“无法提取 key 或 deviceId”的明确错误，不盲目重试密码。

真机尚需验证登录页内容和设备列表 API 兼容性；登录请求不是强行绕过小米身份验证。
