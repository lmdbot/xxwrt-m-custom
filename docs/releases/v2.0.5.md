# XX-WRT管理器 v2.0.5

## 新功能

- **侧栏手势：** 首页、统计、终端、网络、应用一级页面支持从屏幕左侧向右滑动打开设置侧栏，避开页面纵向滚动、图表触摸、弹窗和二级页面。

## 优化

- **终端卡片：** 将“随机 MAC”标签移动到 DHCPv4 标签下方；IP 地址与 MAC 地址尽量同行，窄屏时自动换行。
- **租约显示：** 终端详情将租约剩余秒数换算为天、小时、分钟或秒，并识别永久租约、已到期及未知状态。
- **详情精简：** 删除终端详情中冗长的在线状态判定说明，保留在线状态字段。

## 修复

- **防止误触：** 滑动手势增加起点、方向、位移、时间和垂直滚动校验，新增逻辑回归测试。
