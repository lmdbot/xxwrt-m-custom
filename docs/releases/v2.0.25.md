# XX-WRT Material v2.0.25

## 优化

- “应用 → 防火墙 → 其他规则”中，“已启用”与“已停用”的状态胶囊使用更明确的绿色与红灰色方案，采用深色文字搭配浅色背景，提升状态辨识度。
- 深色主题分别使用深绿色、深红灰色胶囊背景和高亮浅色文字；状态图标及胶囊边框与状态颜色保持一致。
- 同步优化规则开关下方的状态文字颜色，使其与对应胶囊一致。保留已有规则动作标签、开关和操作行为。

## 其他变更

- APP 版本由 2.0.24 升级到 2.0.25。
- 新增页面回归测试，检查启用与停用状态胶囊在深浅色主题下的实际文字与背景对比度均达到至少 4.5:1，同时确保状态切换后样式正确更新。
- 不修改路由器 UCI 配置、RPC 调用、规则数据及防火墙行为。
