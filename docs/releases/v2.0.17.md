# XX-WRT Material v2.0.17

## 修复

- 修复英文语言包中从路由表相关条目开始出现的批量译文错位，消除路由标题、说明、搜索框、筛选计数、状态标签以及进程/启动项等页面的错误英文。
- 补全默认路由、网络路由、主机路由、协议、路由表编号、跃点和条目数量等动态字段的英文翻译。
- 修复 Lucky 内核状态出现“执行权限Healthy”等中英混排的问题，补齐执行权限异常、内核缺失、路径不安全等状态译文，并优化状态详情字段间距。
- 修复 WeChat Push 五个英文标签在窄屏手机上相互遮挡的问题。

## 优化

- Lucky 和 WeChat Push 的标签栏改为按内容宽度布局、支持横向滚动与箭头导航，避免长英文标签被强制压缩；切换行为和功能保持不变。
- 新增英文路由字段、运行状态与 Lucky 动态数据的翻译回归测试，并更新 WeChat Push 标签组件的无障碍交互测试。

## 其他变更

- 本次仅修正应用侧显示和翻译，不修改 QWRT 路由配置或插件数据。
