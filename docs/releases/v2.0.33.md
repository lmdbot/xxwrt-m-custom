# XX-WRT Material v2.0.33

## 新功能

- 新增「网络诊断」：从路由器发起 Ping、Traceroute 和 DNS 查询，区分命令未安装、执行失败和连接不可达，并显示结果与退出码。
- 新增「日志中心」：读取系统日志或内核日志，支持关键词过滤、复制和刷新；根据固件开放的接口选择读取方式。
- 新增「配置备份恢复」：可选择导出 network、dhcp、firewall 和 system 的 UCI JSON 快照；恢复前预览差异，仅变更现有的同名同类型配置节，使用 90 秒临时应用与确认/回滚机制。
- 新增「DNS / DHCP」：管理本地域名静态解析记录与 DHCP 静态租约，校验输入与重复记录，写入后尝试重新加载 dnsmasq。
- 新增「服务管理」：查看路由器服务运行及自启状态，提供授权的启动、停止、重启、启用/禁用自启操作；禁止对管理关键服务执行危险的停用操作。

## 优化

- 将新增五项功能纳入原有「网络与安全」「系统工具」分类与 APP 搜索，维持五个底部主导航，不新增无关入口。
- 网络诊断采用固定可执行路径及参数数组，不开放任意 Shell；无相关 RPC 权限或命令缺失时提示原因。
- 配置恢复加入确认倒计时，避免网络断开后误判成功；写入结果不确定时阻止自动重复执行。
- DNS / DHCP 配置修改前检查未提交的其他变更，避免覆盖 LuCI 中的待保存内容。
- 统一采用页面顶部悬浮提示反馈操作结果。

## 修复

- 补齐 CI 正式发布所需的 v2.0.33 发布说明文件，修复 Material UI 工作流因缺失说明文件而中止的问题。
- 更新 Playwright 应用启动器回归检查，由原来的 17 项更新为 22 项，并验证五个新增工具入口均能显示，修复 Android 构建前 UI 测试阻断。

## 注意

- **配置快照不等于 sysupgrade 完整系统备份**，不会备份所有设备文件、证书、第三方插件数据库或安装包；恢复不会创建原目标设备不存在的配置节。
- 配置快照可能包含 PPPoE 密码及其他敏感信息，应安全保存。Android 系统分享或下载行为需要在实际设备上验证。
- 插件、命令路径及 rpcd ACL 在不同 QWRT/OpenWrt 固件上可能有差异；本版本的自动化模拟测试不等于真实路由器写入兼容性测试。
- 2.0.32 已合入的 HQoS 和多 QoS 后端逻辑在本轮未作改动。
