# XX-WRT Material v2.0.23

## 新功能

- Android APP 原生下载 APK：直接在 APP 内从阿里云 Lucky 更新地址下载，显示百分比和下载体积，支持取消下载，不再使用系统 DownloadManager 或外部浏览器作为 Android 默认下载路径。
- 下载成功后自动调用 Android 系统安装界面；首次使用时可跳转到允许「安装未知应用」设置，返回 APP 后继续打开安装界面。安装操作必须由用户在系统安装器中确认。
- APK 缓存使用应用私有缓存目录，临时文件下载完成前不作为安装包开放，无需申请存储权限；下载完成后可从关于页面再次打开安装器。

## 优化

- 严格校验 APK 下载地址（阿里云或指定 GitHub Release）、文件名、文件大小、SHA-256（镜像必选；GitHub Release 有 digest 时校验）、安装包的包名和版本号；禁止 HTTP 下载和不可信域名重定向。
- 以 AndroidX FileProvider 安全地向系统安装器授予临时只读访问权限，避免使用公有下载目录。
- 沿用阿里云优先、GitHub 备用的版本查询逻辑。网页预览环境仍允许浏览器打开 APK 下载地址，Android 原生环境不再下载失败时自动回退浏览器。

## 其他变更

- 应用版本由 2.0.22 更新为 2.0.23。
- GitHub Actions 在生成 Capacitor Android 工程后注入原生下载与安装模块，并增加 Manifest / FileProvider 单元测试。
- 本功能面向现有 APK 侧载分发流程；如果未来改由 Google Play 分发，需要重新评估 REQUEST_INSTALL_PACKAGES 权限的商店政策要求。
