# XX-WRT管理器 v2.0.12

## 优化

- **设备列表状态排版：** OpenWrt 路由器卡片将在线时长移至“已登录 · 在线”状态胶囊右侧，名称右上角不再重复占位；温度仍在状态行右端，窄屏下在线时长自动省略过长文本。

## 修复

- **系统页面加载闪烁：** 进程、启动项、路由表在读取 RPC 时先显示加载状态，不再提前展示“暂无进程数据”“暂无服务数据”或空路由表。
- **状态区分：** 读取完成后正常显示列表或真实空状态；没有 RPC 权限或查询失败时显示错误，不将其误判为没有记录。
- **手动刷新：** 启动项页面右上角刷新现在会重新读取 rc.list，而不只返回已缓存数据。
- **回归测试：** 验证设备卡片在线时长位置，以及三个系统页面在请求延迟期间不显示伪空状态。
