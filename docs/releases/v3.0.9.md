# XX-WRT v3.0.9

## 优化

- 网络页“网络连接”采用方案 A：外网 WAN 与内网 LAN 上下分组，各自使用独立信息面板。
- 外网 WAN 组聚合 WAN IPv4、WAN6 IPv6、默认网关、DNS、WAN6 剩余有效期及各自连接时长。IPv6 地址完整换行显示。
- WAN / WAN6 连接时长分别读取 netifd 对应运行接口的 uptime（秒），不以系统启动时间代替；未连接显示“未连接”，读取不到显示“--”。
- 内网 LAN 组显示 LAN IPv4、DHCPv4 与 DHCPv6 真实启停状态（开启绿色、关闭灰色、未知灰色）。
- 保持原有蓝色渐变容器、网络管理入口和数据获取方式，改善小屏幕的归属逻辑与可读性。
