# v2.0.30 软件包管理

## 新功能

- 应用 → 系统工具新增“软件包”，参考 OpenWrt LuCI 软件包页面提供可用、已安装、可更新三个列表，支持名称/描述过滤、每页 100 项分页和 LuCI 翻译包显示选项。
- 支持刷新软件源列表、按名称安装、卸载、单包更新、HTTPS .ipk URL 安装和本地 .ipk 上传安装。
- 提供 /overlay 磁盘空间、opkg 配置编辑（原配置 .bak 备份）、操作确认与命令执行输出。

## 优化

- opkg 执行使用 ubus file.exec 的固定程序与参数数组，拒绝命令注入；长操作采用独立 RPC 超时。
- 软件包管理不提供“全部升级”，避免在 OpenWrt/QWRT 上误升级底层系统组件。
- 对 opkg、file.read、file.write RPC 权限不足明确报错；操作超时不自动重试，防止重复安装。

## 注意

- 依赖 QWRT 的 opkg 和 rpcd file.exec/file.read/file.write ACL；不支持采用 apk 包管理器的 OpenWrt 新版本。
- 大于 8 MiB 的本地 .ipk 上传不支持，建议使用 HTTPS URL 安装。
- 需要在真实 QWRT 环境验证 RPC 兼容性、权限、软件包源及上传文件清理行为。
