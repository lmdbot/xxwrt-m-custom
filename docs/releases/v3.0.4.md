# XX-WRT Material v3.0.4

## 优化

- 「我的」页将“关于 / 更新 / 反馈”入口上移至顶部 XX-WRT 管理器信息区，整体信息区可点击进入，路由器退出按钮仍独立操作。
- 「关于」页将“检查更新”按钮及检查状态移至顶部版本号旁，保留版本详情、复制版本、版本日志、安装更新和下载校验功能。
- 统一移动端导航栏边距、操作按钮形态、网络接口配置弹窗和液态底栏宽度，改善窄屏适配。

## 修复

- 修复「工具 → 我的快捷」及软件包、ZeroTier、防火墙、系统管理等多处弹窗的 Android 手势返回穿透问题，优先关闭弹窗而不是退出当前页面。
- 保留配置提交、网络自动回滚和正在执行的安装等关键操作的返回保护。
- 独立升级为 v3.0.4，避免覆盖已发布的 v3.0.3 安装包。
